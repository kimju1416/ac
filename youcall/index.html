유콜 (YOUcall)

사본 만들기부터 전자칠판 앱까지

1

유콜이 뭐예요?

교무실 호출 + 전자칠판 홈스크린, 하나로

유콜은 교사가 교무실 PC에서 학생을 호출하고, 호출이 없을 때 교실 화면(태블릿·전자칠판·TV)은 시간표·급식·학사일정을 보여주는 이중 목적 웹앱이에요. 선생님을 선택하고 → 학년·반을 고르고 → 학생 이름을 누르면, 교실 화면에 크게 호출 알림이 뜨고 음성 안내(TTS)까지 자동으로 나와요.

📣

호출 + 메시지

"시험지 가지고 오세요" 같은 메시지와 어느 교무실로 오라는 위치까지 함께 표시돼요.

🗓️

교실 홈스크린

호출이 없을 때는 오늘 시간표·급식·학사일정·학급 메모를 보여주는 대기화면으로 동작해요.

💡
학교마다 자기 사본을 하나씩 가져가서 씁니다

제 시트를 그대로 쓰는 게 아니라, 아래 02 단계로 학교별 사본을 만들고 그 사본을 각자 배포해서 씁니다. 학생 명단이 서로 섞이지 않아요.

2

사본 만들기

우리 학교만의 유콜을 만드는 첫 단계

아래 버튼을 누르면 구글 시트가 자동으로 내 드라이브에 복사돼요. 원본에는 영향이 없으니 편하게 누르셔도 돼요.

📄 유콜 사본 만들기 구글 계정으로 로그인돼 있어야 해요 · 내 드라이브에 즉시 복사

버튼 클릭

구글 로그인이 안 돼 있으면 로그인 화면이 먼저 뜰 수 있어요. 로그인 후 자동으로 사본 만들기가 진행돼요.

사본 이름 바꾸기

제목을 알아보기 쉽게 바꿔주세요. 예) 유콜 - 00중학교

ℹ️
사본 안에는 이미 다 준비돼 있어요

학생목록·교사목록·설정·호출로그·학사일정 시트와 Code.gs·index.html 코드까지 전부 사본 안에 그대로 들어와요. 새로 만들 건 없고, 값만 채우면 돼요.

3

시트 채우기

학생 명단·교사 명단·학교 설정, 3가지만 넣으면 돼요

방금 만든 사본에서 아래 탭(시트)들을 순서대로 채워주세요.

🧑‍🎓학생목록 시트

열내용
A · 학년예: 1, 2, 3
B · 반예: 1, 2, 3
C · 번호예: 1, 2, 3 …
D · 이름예: 홍길동
E · 표시여부Y = 화면에 표시 / N = 숨김 (전학생 등에 활용)

🧑‍🏫교사목록 시트

열내용
A · 이름예: 김주현
B · 근무위치예: 2학년 교무실 — 학생 화면 호출 알림에 "📍 어디로 오세요"로 그대로 표시돼요

⚙️설정 시트

이 시트만은 표 형태가 아니라, 항목 이름 옆 칸에 값을 채우는 방식이에요. 가장 먼저 챙길 건 딱 하나예요.

🔐
학교명은 꼭 정확하게

"학교명" 칸에 정식 명칭으로 입력하세요 (예: "OO중학교"). 다음 단계(05)의 학교 찾기에서 이 이름으로 찾고, 나이스 정식 이름으로 다시 맞춰 적어 줘요.

그 외 테마(1~5)·자동닫힘시간·시정(1교시 시작시각 등)은 나중에 언제든 바꿀 수 있어요. 지금은 기본값 그대로 두고 넘어가도 괜찮아요.

🍱
점심 없이 끝나는 날은 「점심 시작교시」 칸을 비워요

단축수업처럼 점심이 없으면 점심 시작교시 칸을 비우거나 0으로 두세요. 칠판에 점심 칸이 나오지 않아요. 시간표가 연동된 학교는 요일마다 교시 수가 달라도 따로 적을 필요 없이, 칠판이 그날 시간표의 마지막 교시까지만 보여주고 그 뒤는 「방과후」로 표시해요. 주말에는 「주말」, 공휴일처럼 그날만 수업이 없으면 「오늘은 수업이 없어요」로 떠요. (2026‑09‑12 이후 받은 사본부터)

⏰
「1교시 시작시각」은 앞에 작은따옴표를 붙여 적어주세요

이 칸에 8:40처럼 그냥 치면 구글 시트가 글자가 아니라 「시간」으로 바꿔서 저장해요. 그러면 앱이 그 값을 못 읽고 기본값 08:50으로 교시를 계산해서, 「지금 몇 교시」와 교시별 시간이 학교 시정과 통째로 어긋나요. 칸에 '8:40처럼 맨 앞에 작은따옴표(')를 붙여 입력하면 글자로 저장돼 바로 맞아요. 따옴표는 화면에 보이지 않아요.

📢
공지는 설정 시트가 아니라 교사용 화면에서 써요

교사용 화면 오른쪽 위 「📢 우리 반 공지」 버튼을 누르면 반을 고르고 긴급 공지와 학급 메모를 쓸 수 있어요. 반마다 다른 내용을 쓸 수 있어서 담임 선생님들이 같은 시트를 써도 서로 덮어쓰지 않아요. 전교에 알릴 일은 전체를 고르면 돼요. 쓴 내용은 「학급공지」 시트에 한 반씩 쌓이니, 시트에서 직접 고쳐도 됩니다.

🔎
글자가 작아 보이면 크기를 키울 수 있어요

공지를 쓰는 창에서 문구 옆 「크기」 칸을 1단계~5단계 중에 고르면 돼요. 1단계가 지금까지의 크기이고 숫자가 커질수록 크게 보여요. 교실 뒤에서도 읽히게 하려면 3~4단계를 권해요. 고르는 대로 미리보기가 바뀌니 교실에 가보지 않아도 확인할 수 있어요. 화면을 넘칠 만큼 크게 고르면 잘리지 않는 선까지 자동으로 맞춰 주니 마음껏 골라도 돼요. 작은 칠판(1280×720 등)에서 공지를 아주 크게 고르면 급식·시간표 자리를 지키려고 공지가 조금 작아질 수 있어요 — 학생이 봐야 할 시간표가 먼저 보이도록 하기 위한 동작이에요.

💡
담임 선생님은 자기 반이 자동으로 잡혀요

교사목록 시트의 「담임학급」 칸(C열)에 1-2처럼 적어두면, 공지를 쓸 때 그 선생님 이름을 고르는 순간 자기 반에 「담임」 표시가 붙고 자동으로 선택돼요. 비워둬도 반을 손으로 고르면 되니 급하지 않아요. 한 번에 1-1·1-3처럼 여러 반을 골라 같은 공지를 보낼 수도 있어요.

📝
학급 메모는 줄을 바꿔 길게 쓸 수 있어요

메모 칸에서 Enter로 줄을 바꾸면 칠판에도 그대로 줄이 바뀌어 보여요(최대 600자). 메모 칸 위 단추로 • 목록 · ☐ 체크 · ☑ 완료 · 오늘 날짜 · 다음 평일을 넣을 수 있고, 자주 쓰는 말은 상용구, 지난번 메모는 최근 메모 불러오기로 다시 꺼내 써요. 창 오른쪽 칠판 미리보기는 실제 칠판 크기(1920×1080·1600×900·1366×768·1280×720)로 그려서 「다 보임 · 글자가 작아짐 · 넘침」을 알려 줘요. 「넘침」이 뜨면 글을 줄이거나 크기를 낮추세요. 크게 보기를 누르면 칠판을 화면 가득 볼 수 있어요. (2026‑09‑12 이후 받은 사본부터)

🗓️학사일정 시트

비워둬도 돼요. 학교 행사(방학식·시험·공휴일 등)는 NEIS 학사일정에서 자동으로 불러와 D-day로 표시돼요. 수학여행처럼 따로 알리고 싶은 일정이 있을 때만 이 시트에 날짜 | 제목으로 직접 추가하면 자동 일정과 함께 표시되고, 행을 지우면 바로 사라져요.

💡
NEIS API 키는 발급받지 않아도 돼요

급식·시간표·학사일정 자동연동에 필요한 인증키가 이 사본에 이미 내장돼 있어요. 학교명만 정확히 입력하면 다음 단계에서 바로 연동돼요.

🗣️호출 음성 바꾸기 (선택 · 타입캐스트)

호출할 때 나오는 음성은 기본이 구글 음성이에요. 더 자연스러운 목소리를 원하면 타입캐스트(typecast.ai) 목소리를 쓸 수 있어요 — 남자 「필재」와 여자 「한영」 중에 골라요. (2026‑09‑12 이후 받은 사본부터)

API 키 발급

typecast.ai에 가입하고 API 키를 발급받아요. 음성은 키를 넣은 계정의 크레딧으로 만들어져요(요금·크레딧은 타입캐스트 요금제를 따라요).

설정 시트에 붙여넣기

설정 시트 맨 아래 호출 음성 — 타입캐스트 API 키 칸에 키를 붙여넣고, 바로 아래 호출 음성 — 타입캐스트 목소리에서 남자 (필재)·여자 (한영)를 골라요.

확인

유콜 ▸ 호출 음성 확인 — 타입캐스트를 누르면 키를 확인하고, 칸이 「✅ 등록됨 · 남은 크레딧」으로 바뀌어요. 키는 안전한 곳으로 옮겨지고 시트 칸에는 남지 않아요.

ℹ️
키를 비워 두면 지금처럼 구글 음성이에요

크레딧이 떨어지거나 키가 잘못돼도 호출이 조용해지지 않도록 자동으로 구글 음성으로 나와요. 웹·EXE·APK 모두 따로 설치할 것 없이 적용돼요.

Apps Script 열기

사본 스프레드시트 상단 메뉴에서 확장 프로그램 ▸ Apps Script를 클릭합니다.

새 창이 열리면 오른쪽 위 배포 버튼 ▸ 새 배포를 클릭합니다.

유형 선택

톱니바퀴(⚙) 아이콘을 눌러 "웹 앱"을 선택합니다.

설명 입력

알아보기 쉬운 이름을 적어요. 예) 유콜 웹앱

실행 사용자 · 액세스 권한 설정 (가장 중요)

"다음 사용자 인증으로 실행"은 반드시 나(Me), "액세스 권한"은 반드시 모든 사용자(Anyone)로 선택합니다.

배포 클릭

배포 버튼을 누르면 권한 승인 화면이 뜹니다. 바로 아래 "보안 경고가 뜨면" 순서대로 처리하면 돼요.

URL 복사

승인이 끝나면 웹앱 URL이 생성됩니다. 이 주소를 꼭 복사해서 어딘가에 저장해두세요.

⚠️
실행 사용자·액세스 권한은 틀리면 안 돼요

"나"가 아닌 다른 값을 고르거나 "모든 사용자"가 아니면, 학생 화면이 열리지 않거나 매번 로그인을 요구할 수 있어요.

🔓보안 경고가 뜨면

배포 버튼을 누르면 "이 앱은 확인되지 않았습니다" 라는 경고가 뜰 수 있어요. 당황하지 않으셔도 돼요 — 본인이 직접 만든 앱이라 안전합니다. 구글이 개인이 만든 모든 스크립트를 일일이 검증할 수 없어서 뜨는 안내일 뿐이에요.

주소 확인 · 학교코드 연결

URL 두 종류 구분하기 + 급식·시간표 자동연동 마무리

용도주소 형태

⚠️
교사용 주소는 시트 메뉴에서 확인해요

스프레드시트를 새로고침한 뒤 유콜 ▸ 교사용 주소 보기를 누르면 교사용 주소가 떠요. 처음 한 번은 칠판(학생용) 주소를 붙여넣으라고 물어봐요 — 방금 복사한 웹앱 URL(…/exec)을 붙여넣으면 돼요. 이 주소를 교무실 PC 즐겨찾기에 저장하세요. 주소 끝에 ?role=teacher만 붙여서 열면 「교사용 주소가 바뀌었습니다」 안내만 나오고 교사 화면은 열리지 않아요. (2026‑09‑12 이전에 받은 사본은 예전처럼 ?role=teacher만 붙이면 열려요.)

🔐
교사용 주소는 교직원끼리만 공유하세요

교사용 화면에는 전교생 명단(학년·반·번호·이름)이 들어 있어요. 학생·학부모나 외부, 메신저 단체방·게시판처럼 공개된 곳에 올리지 마세요. 혹시 새어 나갔다면 유콜 ▸ 교사용 주소 보기에서 [예]를 누르세요. 새 주소로 바뀌고 옛 교사용 주소는 바로 막혀요 — 선생님들께 새 주소만 다시 알려 주면 돼요. 교실 칠판(학생용) 주소는 바뀌지 않아요.

💡

Apps Script ▸ 배포 ▸ 배포 관리에서 활성 배포의 URL을 언제든 다시 볼 수 있어요.

설정 시트에 학교명·교육청코드·학교코드가 채워지고, 이때부터 급식·시간표가 매일 자동 갱신돼요. 컴시간에도 있는 학교면 시간표를 컴시간에서 받을지 이어서 물어봐요.

🍱
급식은 화면 크기에 맞춰 알아서 표시돼요

중식만 있는 학교는 한 칸에, 중식·석식 두 끼니가 나오는 학교는 좌우로 나란히 보여줘요. 자리가 남으면 급식 글자가 자동으로 커지고, 메뉴가 많아 넘칠 것 같으면 다 보이는 선까지 줄여요. 조식까지 세 끼니가 나오는 기숙사 학교도 잘리지 않게 배치돼요.

학교 찾기 한 번이면 돼요

위의 유콜 ▸ 학교 찾기 (급식·시간표 연결)가 나이스에서 고른 학교를 컴시간에서도 자동으로 찾아 줘요. 이름이 같은 학교가 여럿이면 지역으로 가려내고, 그래도 헷갈리면 번호를 고르게 해요.

컴시간으로 받기

「시간표를 컴시간에서 받을까요?」에서 예를 누르면 설정 시트의 시간표 출처가 컴시간으로 바뀌어요. 그 학교 시간표가 실제로 받아지는지도 먼저 확인해 줘요.

나중에 바꾸려면

설정 시트의 시간표 출처에서 나이스·컴시간을 직접 골라도 돼요. 컴시간에 없는 학교는 자동으로 나이스로 둬요.

💡
교체 수업은 이렇게 보여요

오늘 시간표의 바뀐 교시에 「교체」 표시와 원래 과목이 함께 뜨고, 이번주 시간표에서는 바뀐 칸이 노란색으로 표시돼요. 컴시간이 잠시 안 될 때는 자동으로 나이스 시간표를 보여주니 칠판이 비지 않아요. 칠판 앱(EXE·APK)에서 교체 표시를 보려면 최신판으로 갱신해 주세요(08·09).

💡

바꾸는 방법이 서로 조금 달라요

APK는 ⚙️ 설정 화면에서 두 모드 중 하나를 바로 고릅니다. EXE는 트레이 아이콘 우클릭 메뉴의 체크박스 두 개(상시화면 표시 · 새 호출 시 창 자동 복원) 조합으로 같은 효과를 냅니다 — 둘 다 켜면 상시 화면형, "상시화면 표시"만 끄고 "자동 복원"을 켜면 상주형과 동일하게 동작해요.

⚠️
상주형은 대기화면이 안 보여요

평소 화면이 꺼져 있으므로 긴급공지·학급메모·시간표가 보이지 않아요. 공지를 학생들에게 계속 보여주려면 상시 화면형을 쓰세요.

문제 해결 · 삭제

자주 묻는 질문과 앱 삭제 방법

  • 호출이 2~3초 뒤에 떠요 — 정상이에요. 구글 서버를 거쳐 오는 구조라 2~3초 정도 걸려요. 웹·EXE·APK 모두 동일해요.
  • 교사 화면이 안 열려요 · 「교사용 주소가 바뀌었습니다」가 떠요 — 교사 화면은 시트 메뉴 유콜 ▸ 교사용 주소 보기에 나오는 주소로 열어야 해요(05). 누군가 메뉴에서 주소를 새로 바꿨다면 옛 즐겨찾기는 막혀요 — 메뉴에서 새 주소를 받아 즐겨찾기를 바꾸세요. (2026‑09‑12 이전에 받은 사본은 주소 끝에 ?role=teacher가 정확히 붙어 있는지 확인하세요.)
  • 소리가 안 나요 — 웹은 시작 화면에서 시작하기를 눌렀는지(브라우저 정책상 첫 클릭이 필요해요), EXE·APK는 🔊 버튼에서 볼륨과 호출음을 확인하고 소리 테스트를 눌러보세요.
  • 「지금 몇 교시」와 교시 시간이 우리 학교 시정과 안 맞아요 — 설정 시트의 1교시 시작시각을 구글 시트가 글자가 아니라 「시간」으로 바꿔 저장해서 생기는 문제예요. 앱이 그 값을 못 읽고 기본값 08:50으로 계산하기 때문에 교시가 통째로 밀려 보여요. 그 칸에 '8:40처럼 맨 앞에 작은따옴표(')를 붙여 다시 입력하고 화면을 새로고침(F5)하면 바로 맞습니다. 따옴표는 화면에 보이지 않아요. (2026‑09‑08 이후 받은 사본은 이 처리가 되어 있어요.)
  • 점심 이후 교시가 10분쯤 늦게 나와요 — 예전 판은 4교시가 끝나고 쉬는시간 10분이 지난 뒤에 점심이 시작하는 것으로 계산했어요. 2026‑09‑08 판부터는 점심이 그 교시가 끝나는 즉시 시작합니다. 웹은 자동으로 반영되고, EXE·APK는 최신판을 다시 설치해야 바뀝니다(08·09 참고). 예전에 사본을 받아 그대로 쓰고 계신다면, 설정 시트의 점심시간(분)을 실제보다 10분(쉬는시간만큼) 적게 적으면 점심 이후 교시가 맞게 나와요. 반대로 4교시 뒤 따로 쉬었다가 급식을 가는 학교는 점심시간(분)에 그 쉬는시간까지 포함해 적으시면 됩니다.
  • 급식·시간표·학사일정이 안 나와요 — 설정 시트의 학교명이 정확한지, 유콜 ▸ 학교 찾기 (급식·시간표 연결)(예전 사본은 학교코드 조회)를 실행했는지 확인하세요. 급식·시간표는 방학·주말에는 원래 표시되지 않아요.
  • 공지·메모를 바꿨는데 화면에 안 떠요 — 공지를 보낼 때 고른 반이 그 교실이 맞는지 먼저 확인하세요(전교에 알리려면 전체). 웹·EXE·APK 모두 3분 안에 자동으로 반영되니 새로고침하지 않아도 됩니다.
  • 예전에 받은 사본에도 새 기능이 생기나요? — 아니요. 사본은 받은 날의 판 그대로예요(교사용 주소 열쇠·학교 찾기·컴시간 교체 표시·메모 줄바꿈·호출 음성은 2026‑09‑12 이후 받은 사본부터). 새 기능을 쓰려면 01부터 새 사본을 받아 학생목록·교사목록·설정을 옮겨 적고 새로 배포하세요. 새 사본은 주소가 달라지니 칠판 앱 설정의 웹앱 주소도 새 주소로 바꿔야 해요. 지금 사본으로 계속 써도 되고, 칠판 앱을 최신판으로 갱신해도 예전 사본과 그대로 잘 맞아요.
  • 칠판 위쪽에 「유콜이 새 판으로 바뀌었습니다 — 이 화면을 새로고침(F5)해 주세요」가 떠요 — 웹 칠판을 켜 둔 채로 유콜이 새 판으로 바뀐 경우예요. 그 화면에서 F5(새로고침)를 한 번 누르고 반을 다시 고르면 사라져요. 새로고침하기 전까지는 호출이 오지 않을 수 있으니 꼭 눌러 주세요. EXE·APK 칠판에는 뜨지 않아요.
  • 메모 뒷부분이 칠판에서 안 보여요 — 공지 창의 칠판 미리보기에서 우리 교실 칠판 크기를 골라 「넘침」이 뜨는지 보세요. 넘침이면 글을 줄이거나 크기 단계를 낮추면 돼요. 칠판 화면이 작을수록(1280×720 등) 들어가는 글자가 적어요.
  • 컴시간으로 바꿨는데 교체 수업이 안 보여요 — 설정 시트의 시간표 출처가 컴시간이고 컴시간 학교코드가 채워져 있는지 확인하세요. 컴시간이 잠시 안 되면 나이스 시간표가 대신 나와요. 시간표는 칠판이 30분마다 새로 받으니 바로 안 바뀌어도 기다려 주세요. 칠판 앱(EXE·APK)은 최신판이어야 교체 표시가 보여요.
  • 상주형 APK인데 호출 화면이 안 떠요 — 「다른 앱 위에 표시」 권한이 꺼져 있을 수 있어요. 설정 ▸ 애플리케이션 ▸ 유콜 보드 (호환) ▸ 권한에서 켜주세요.
  • 호출이 두 번씩 울려요 — 예전 「유콜 보드」와 새 「유콜 보드 (호환)」이 칠판에 둘 다 깔려 있을 수 있어요. 설정 ▸ 애플리케이션에서 예전 「유콜 보드」를 지우세요(09).
  • EXE 설치할 때 파란 경고 화면이 떠요 — 윈도우 SmartScreen이에요. 추가 정보 ▸ 실행을 누르면 진행됩니다. 스토어를 거치지 않은 프로그램이면 다 뜨는 정상적인 경고예요.
  • EXE를 완전히 끄고 싶어요 — 트레이 아이콘(작업표시줄 오른쪽 하단)을 우클릭 ▸ 종료를 누르세요. X 버튼만 누르면 트레이로 숨을 뿐 계속 실행 중이에요.
  • 학생을 추가/삭제했는데 반영이 안 돼요 — 시트 저장 후 화면에서 새로고침(F5)하면 즉시 반영돼요. 재배포는 필요 없어요.
  • 교실마다 다르게 써도 되나요? — 됩니다. 1반은 웹, 2반은 EXE, 3반은 APK로 써도 서로 아무 영향 없어요.

APK — 앱 아이콘을 길게 눌러 [제거]로 끌어다 놓거나, 설정 ▸ 애플리케이션 ▸ 유콜 보드 (호환) ▸ [제거]를 누르세요.
