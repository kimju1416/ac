Claude.ai
Anthropic · claude.ai
글쓰기·분석·코딩에서 최상위 성능을 보이는 AI. 자연스러운 한국어 작문이 강점이에요. 최상위 모델은 9.1 출시된 Fable 5.1 — Opus 위에 신설된 Mythos급 티어로, Fable 5보다 성능은 높이고 비용은 약 25% 낮췄어요(Max 요금제는 주간 한도의 최대 50%까지 기본 포함, Pro는 사용 크레딧 과금, 무료 요금제는 사용 불가). 9월 하순엔 Claude 5.5 패밀리가 시작됐어요 — Opus 5.5(9.22, Pro 이상)는 대부분 작업에서 Fable 5.1급 성능을 내면서 Opus 5보다 약 40% 저렴하고, Sonnet 5.5(9.28)는 무료 요금제에서도 쓸 수 있어요(Haiku 5.5는 출시 예정). 9.16부터는 채팅과 Cowork가 하나의 Claude로 합쳐져서, 같은 대화 안에서 질문도 하고 일도 맡길 수 있어요(Pro·Max부터 순차 적용). 최대 100만 토큰 컨텍스트(모델별 차이)로 긴 문서도 한 번에 처리하고, 환각(잘못된 정보 생성)이 낮은 편이에요. Projects로 프로젝트별 맞춤 AI 공간을 만들고, Artifacts로 대화 중 코드·문서·차트를 실시간 미리보기 가능. MCP 연동으로 Gmail·캘린더·Drive까지 직접 연결.

ChatGPT
OpenAI · chatgpt.com
전 세계 사용자 수 1위, 가장 범용적인 올인원 AI. 2026년 7월부터 GPT-5.6 패밀리(Sol·Terra·Luna)로 세대교체됐고, 9월 3일에는 최상위 모델 GPT-6 Astra가 공개됐어요(Pro·Business·Enterprise 요금제부터 적용, Plus는 Work·Codex 안에서 횟수 제한으로 사용). 9월 22일에는 GPT-6 Sol·Luna, 9월 29일에는 Astra에 가까운 성능을 1/5 가격에 내는 GPT-6.1 Sol이 나왔는데, 모두 아직은 일반 채팅 창이 아니라 ChatGPT Work(일 맡기기 모드)와 Codex에서만 쓸 수 있어요. 8월부터는 무료 티어도 텍스트 채팅이 무제한으로 열렸어요(무료는 Luna 모델 — 이미지 생성·파일 업로드·음성은 한도 유지). 대화·이미지 생성(GPT Image)·음성 대화·Deep Research·코드 실행·파일 분석을 하나의 앱에서 모두 처리해요. Custom GPT를 만들어 반복 작업을 자동화할 수 있고, Memory 기능으로 대화 맥락을 기억. "이 문서 읽고 요약한 뒤 인포그래픽으로 만들어줘"처럼 여러 작업을 한 흐름에서 연결.

Google DeepMind · gemini.google.com
