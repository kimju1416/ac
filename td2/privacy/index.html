TeacherDesk 2 · 시행일 2026년 8월 17일 · 만든 사람 김주현(광평중학교)

1한 줄로 말하면

학생 정보는 선생님 컴퓨터를 벗어나지 않습니다. 명렬·생기부 초안·메모·일정은 이 프로그램을 만든 사람도 볼 수 없습니다. 서버에 올리지 않기 때문입니다.

다만 딱 두 가지는 인터넷을 씁니다. 그래야 되는 기능이라서입니다.

  • AI 기능 — 선생님이 적은 글이 구글로 갑니다 (3번 항목)
  • 급식·학사일정·날씨 — 학교 코드와 지역 이름만 나갑니다 (3번 항목)

여기에 더해, 몇 분이 쓰시는지 세는 익명 집계가 하루 한 번 있습니다. 이건 설정에서 끌 수 있고, 꺼도 모든 기능이 그대로 동작합니다 (4번 항목).

2컴퓨터에 저장되는 것

전부 %APPDATA%\TeacherDesk2 폴더에 저장됩니다. 서버로 보내지 않습니다.

무엇예
명렬학생 번호·이름·비고
생기부 초안작성한 글, 그때 적어둔 학반·이름, 저장한 글 목록
학교 업무할 일, D-Day, 일정, 메모, 시간표, 내선번호
설정학교 정보, 화면 배치, API 키
서랍바탕화면의 실제 폴더입니다. 프로그램은 위치만 기억합니다
파일 자체는 암호로 잠겨 있지 않습니다. 컴퓨터 로그인 암호가 1차 보호막입니다. 학교 공용 PC라면 윈도우 계정을 나눠 쓰시길 권합니다. 다만 API 키만은 예외로 암호화해 둡니다 — 파일을 복사해 다른 계정·다른 컴퓨터로 옮기면 풀리지 않습니다.

3밖으로 나가는 것 (전부)

여기 적힌 것이 전부입니다. 이 밖에 나가는 것은 없습니다.

가. AI 기능 — 구글 Gemini

AI 도우미·생기부 초안·파일 불러오기를 쓰실 때, 입력창에 적은 글과 고르신 파일의 내용이 구글로 전송됩니다. 생기부의 학반·이름은 빼고 보냅니다(그건 컴퓨터에만 남는 표시입니다).

구글이 이 내용을 어떻게 다루는지는 구글의 Gemini API 약관을 따릅니다. 쓰시는 키의 등급에 따라 다르니, 필요하시면 그 문서를 확인해 주세요.

그래서 이렇게 쓰시길 권합니다 — 입력창에 학생 실명·주민등록번호·연락처·가정환경을 적지 마세요. 생기부 초안은 이름 없이 관찰 내용만 적어도 충분히 나옵니다. AI 기능을 아예 안 쓰실 수도 있습니다. 키를 안 넣으시면 됩니다.

나. 급식 · 학사일정 (NEIS)

학교 코드만 나갑니다. 학생 정보는 나가지 않습니다.

다. 날씨 · 미세먼지

지역 이름(좌표)만 나갑니다. 학교 주소로 한 번 찾아둔 지역입니다.

라. 익명 사용 집계

하루에 한 번, 아래 네 가지만 보냅니다.

무작위 번호 · 앱 이름 · 앱 버전 · 윈도우 버전

무작위 번호는 그 컴퓨터에서 만든 난수라 누구인지 되짚을 수 없습니다. 몇 분이 쓰고 계신지, 옛 버전에 몇 분이 남아 계신지를 알아야 고친 내용을 제때 전할 수 있어 두었습니다.

마. 오류 기록

프로그램이 예상 못 한 오류로 꺼지면, 다음에 켤 때 그 기록을 보냅니다. 어디서 왜 꺼졌는지 알아야 고칠 수 있어서입니다.

파일 경로는 통째로 버리고 확장자만 남깁니다. 파일 이름이 곧 학생 이름인 경우가 많기 때문입니다. 실제로 이렇게 바뀝니다.
… open 'C:\Users\…\3학년 2반 김○○ 관찰기록.hwp'
↓ 이렇게만 나갑니다
… open '<파일>.hwp'

하루 5건까지만 보내고 같은 오류는 한 번만 셉니다. 무엇이 나갔는지 직접 보실 수 있습니다 — 설정 → 도움말 → [내 오류 기록 보기].

바. 의견 보내기

[보내기]를 누르셨을 때만 나갑니다. 적으신 내용과 앱 버전·윈도우 버전이 갑니다. 전부 익명이라 누가 보내셨는지 알 수 없고, 그래서 답장도 드릴 수 없습니다.

사. 공지 · 새 버전 확인

받아만 옵니다. 이 길로 나가는 것은 없습니다.

4끄는 방법

설정 → [의견] 탭 → 「이 컴퓨터가 쓰고 있다고 알리기」 체크를 끄시면 됩니다. 사용 집계와 오류 기록이 함께 꺼집니다.

꺼도 모든 기능이 그대로 동작합니다. 기능을 담보로 잡지 않습니다. 끄면 보내고 나서 숨기는 것이 아니라, 보내는 동작 자체가 일어나지 않습니다.

6파일로 내보낼 때

내보낸 파일은 개인정보 파일입니다. 설정 백업(.tdbk)에는 명렬과 생기부 저장글이 함께 들어가고, 생기부 엑셀·한글·CSV에도 학반·이름이 들어갑니다. USB·메신저로 옮기실 때는 그렇게 다루시고, 옮긴 뒤에는 지워 주세요.

7이 프로그램이 지키는 것

  • API 키는 암호화해 저장합니다 — 윈도우 계정에 묶인 방식이라, 파일만 복사해 가도 풀 수 없습니다.
  • 오류 기록의 파일 경로는 지우는 게 아니라 통째로 버립니다 — 골라 지우면 무엇을 빠뜨렸는지 알 수 없기 때문입니다.
  • 집계 서버는 넣기만 되고 읽기는 막혀 있습니다 — 프로그램 안에 든 열쇠로는 남의 기록을 볼 수 없습니다.
  • 말로만 하지 않고 검사로 확인합니다 — 배포 전마다 학생 이름이 든 가짜 자료를 심어놓고, 실제로 나가는 문자열을 가로채 한 글자라도 섞이면 배포를 막습니다.

8학교에 설명하실 때

“교사 개인 PC에 설치해 쓰는 프로그램이며, 학생 정보는 이 컴퓨터에만 저장되고 외부 서버로 전송되지 않습니다. AI 기능을 쓸 때만 입력한 문장이 구글 Gemini로 전송되며 학생 이름은 포함하지 않습니다. 급식·학사일정은 학교 코드만, 날씨는 지역명만 조회합니다. 사용 집계는 무작위 번호와 버전뿐이며 설정에서 끌 수 있습니다.”

학교마다 규정이 다릅니다. 업무용 컴퓨터에 프로그램을 설치하는 기준, 그리고 생활기록부 작성에 AI를 쓰는 것에 대한 교육청·학교의 지침이 따로 있을 수 있습니다. 이 문서는 “무엇이 어디로 가는지”를 정확히 알려드리는 것까지고, 쓰셔도 되는지는 소속 학교의 정보 담당 선생님께 확인해 주세요.

9만 14세 미만

이 프로그램은 교사가 쓰는 업무 도구입니다. 학생이 직접 설치해 쓰거나 학생에게서 정보를 직접 수집하지 않습니다.
