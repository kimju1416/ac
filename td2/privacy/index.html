개인정보 처리방침

TeacherDesk 2가 무엇을 저장하고, 무엇을 밖으로 보내는지 밝힌 문서입니다. 학교에 설명하셔야 할 때 이 주소를 그대로 보여 주시면 됩니다.

TeacherDesk 2 · 시행일 2026년 9월 13일 · 만든 사람 김주현(광평중학교)

1한 줄로 말하면

기본은 선생님 컴퓨터에만 저장됩니다. 명렬·출결·일정·메모 같은 기록은 이 프로그램을 만든 사람도 볼 수 없습니다. 만든 사람의 서버에 올리지 않기 때문입니다.

선생님이 「PC 사이 맞추기」에 구글 계정으로 로그인하신 경우에만, 같은 기록이 선생님 본인 구글 드라이브의 앱 전용 칸에도 저장됩니다(3번 항목). 이것도 만든 사람은 볼 수 없습니다.

급식·학사일정·날씨는 인터넷을 씁니다 — 나가는 것은 학교 코드와 지역 이름뿐입니다(4번 항목). 여기에 더해 몇 분이 쓰시는지 세는 익명 집계가 하루 한 번 있고, 설정에서 끌 수 있습니다(5번 항목).

2컴퓨터에 저장되는 것

전부 %APPDATA%\TeacherDesk2 폴더에 저장됩니다.

무엇예
명렬학생 번호·이름·비고, 넣으셨다면 학생·부모 연락처와 선택과목
학급 기록출결, 누가기록(활동·상담), 생기부 저장글
학교 업무할 일, D-Day, 일정, 메모, 진도, 시간표, 주간학습안내, 내선번호
설정학교 정보, 화면 배치·디자인, API 키, 구글 캘린더 주소, 앨범 사진
서랍바탕화면의 실제 폴더입니다. 프로그램은 위치만 기억합니다

파일 자체는 암호로 잠겨 있지 않습니다. 컴퓨터 로그인 암호가 1차 보호막이니, 학교 공용 PC라면 윈도우 계정을 나눠 쓰시길 권합니다. 다만 API 키·구글 캘린더 주소·업무포털 인증서 비밀번호·구글 로그인 정보는 암호화해 두어, 파일을 복사해 다른 계정·다른 컴퓨터로 옮기면 풀리지 않습니다.

3PC 사이 맞추기 (구글 드라이브)

학교 PC와 집 PC처럼 여러 컴퓨터에서 같은 기록을 쓰고 싶은 분을 위한 기능입니다. 기본은 꺼져 있고, 설정 → [데이터] 탭에서 [구글로 로그인]을 누르셨을 때만 켜집니다.

어디에 저장되나요

  • 로그인한 선생님 본인의 구글 드라이브 안 «앱 전용 칸»(appDataFolder)입니다. 드라이브 목록에는 보이지 않습니다.
  • 이 프로그램은 그 칸만 쓸 수 있고, 선생님의 다른 드라이브 파일은 볼 수 없습니다.
  • 만든 사람의 서버를 거치지 않습니다. 저장 공간은 선생님 구글 계정 용량을 씁니다.

구글에 요청하는 권한 (이 셋이 전부입니다)

권한쓰는 곳
drive.appdata앱 전용 칸에 맞춤 자료를 저장하고 읽기
email어느 계정으로 맞추고 있는지 설정 화면에 보여 드리기
openid로그인 확인

함께 옮겨지는 것

  • 할 일·일정·메모·진도·시간표·출결·명렬(연락처 포함)·누가기록·생기부 저장글
  • 설정·위젯 위치·디자인, API 키·나이스 키·구글 캘린더 주소
  • 앨범 사진·주간학습안내 원본 파일(한 파일 10MB까지)

옮기지 않고 컴퓨터마다 남는 것

  • 업무포털·업무 메신저 자동 로그인 설정과 인증서 비밀번호
  • 독에 꽂은 프로그램·파일, 서랍 폴더, 창 모드·쓸 모니터

구글에서 받은 정보를 쓰는 원칙

TeacherDesk 2가 구글 API로 받은 정보를 쓰고 옮기는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다. 받은 정보는 선생님의 컴퓨터끼리 기록을 맞추는 데에만 쓰고, 광고에 쓰거나 다른 사람에게 넘기거나 팔지 않으며, 만든 사람을 포함해 누구도 사람이 직접 읽지 않습니다.

끄고 지우는 방법

  • [로그아웃] — 그 컴퓨터의 기록은 그대로 남고, 그때부터 다시 그 컴퓨터에만 저장됩니다.
  • [드라이브에 올린 자료 지우기] — 구글 드라이브의 맞춤 자료를 모두 지우고 로그아웃합니다. 다른 컴퓨터에서도 로그아웃해 주셔야 그 컴퓨터가 다시 올리지 않습니다.
  • 구글 계정에서 직접 끊으실 수도 있습니다 — 구글 계정 → 연결된 앱에서 TeacherDesk2의 액세스를 삭제하세요.

4밖으로 나가는 것

가. 급식 · 학사일정 · 시간표 (NEIS)

학교 코드만 나갑니다. 학생 정보는 나가지 않습니다.

나. 날씨

지역을 찾을 때 학교 주소 일부·학교 이름(또는 넣으신 지역명)이, 그 뒤로는 좌표만 나갑니다.

다. 구글 캘린더 · 전광판 시트 · 컴시간 · 새 버전 확인

넣으신 주소·학교로 받아 오기만 합니다.

라. PC 사이 맞추기

로그인하신 경우에만, 3번 항목의 기록이 선생님 본인 구글 드라이브로 갑니다.

마. 익명 사용 집계

하루에 한 번 무작위 번호 · 앱 이름 · 앱 버전 · 윈도우 버전 네 가지만 보냅니다. 무작위 번호는 그 컴퓨터에서 만든 난수라 누구인지 되짚을 수 없습니다.

바. 오류 기록

프로그램이 예상 못 한 오류로 꺼지면, 다음에 켤 때 그 기록을 보냅니다. 파일 경로는 통째로 버리고 확장자만 남깁니다 — 파일 이름이 곧 학생 이름인 경우가 많기 때문입니다. 하루 5건까지만 보내고 같은 오류는 한 번만 셉니다. 업무포털 자동 로그인이 실패했을 때는 어느 단계에서 멈췄는지와 그때 뜬 문구가 함께 갑니다(인증서 아이디·비밀번호·학교 이름은 나가지 않습니다).

사. 의견 보내기와 답장

[보내기]를 누르셨을 때만 적으신 내용과 앱 버전·윈도우 버전이 갑니다. 답장은 그 컴퓨터의 무작위 번호로 보낸 의견에만 돌아오므로 다른 분의 의견은 볼 수 없습니다.

아. 공지

받아만 옵니다. 이 길로 나가는 것은 없습니다.

5끄는 방법

  • 사용 집계·오류 기록 — 설정 → [의견] 탭의 체크 하나로 함께 꺼집니다. 꺼도 모든 기능이 그대로 동작합니다.
  • PC 사이 맞추기 — 설정 → [데이터] 탭 → [로그아웃].

7파일로 내보낼 때

내보낸 파일은 개인정보 파일입니다. 설정 백업(.tdbk)에는 명렬·생기부 저장글·누가기록(상담 포함)·출결이 들어가고, 엑셀·한글·CSV에도 학반·이름이 들어갑니다. USB·메신저로 옮기실 때는 그렇게 다루시고, 옮긴 뒤에는 지워 주세요.

8학교에 설명하실 때

“교사 개인 PC에 설치해 쓰는 프로그램이며, 기록은 이 컴퓨터에 저장되고 만든 사람의 서버로 전송되지 않습니다. 여러 PC에서 쓰려고 로그인한 경우에만 교사 본인 구글 드라이브의 앱 전용 공간에도 저장됩니다. 급식·학사일정은 학교 코드만, 날씨는 지역명만 조회하며, 사용 집계는 무작위 번호와 버전뿐이고 설정에서 끌 수 있습니다.”

학교마다 규정이 다릅니다. 업무용 컴퓨터에 프로그램을 설치하는 기준이나 개인 클라우드에 학생 정보를 두는 것에 대한 교육청·학교 지침이 따로 있을 수 있으니, 쓰셔도 되는지는 소속 학교의 정보 담당 선생님께 확인해 주세요.
