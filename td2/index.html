바탕화면이 곧 교무 비서가 됩니다

TeacherDesk 2는 시계·날씨·급식·시간표·학사일정·할 일·D-Day에 AI 도우미와 생기부 초안까지, 선생님에게 필요한 것들을 바탕화면 위젯으로 펼쳐 두는 프로그램이에요. 브라우저를 열 필요 없이, 컴퓨터를 켜면 바로 보입니다.

지금 다운로드Windows 10 · 11 · 무료 파일 하나만 받아 실행하면 끝입니다.

어떤 프로그램인가요

바탕화면에 얹는 선생님용 위젯 대시보드예요.

컴퓨터를 켜면 바탕화면에 시계·날씨·오늘 급식·주간 시간표·학사일정·할 일·D-Day·메모·달력이 카드로 펼쳐집니다. 학교만 한 번 등록하면 급식과 학사일정, 날씨가 자동으로 채워져요. 여기에 AI 도우미(공지에서 할 일·마감일 뽑기 · 공문서 다듬기 · 생기부 초안)까지 붙어 있어, 브라우저를 오갈 필요가 줄어듭니다.

이런 분께 잘 맞아요

여러 탭을 띄워 두기 싫은 분, 급식·시간표·할 일을 한눈에 보고 싶은 분, 생기부·공문서를 AI로 빠르게 다듬고 싶은 분.

항목내용
지원 환경Windows 10 · 11 (맥·모바일은 지원하지 않아요)
설치 크기약 100MB · 설치 후 자동 실행 & 트레이 상주
비용완전 무료 · 계정 가입 없음
데이터 저장명렬 · 생기부 초안 · 메모 · 일정은 내 컴퓨터에만 저장 (외부 서버로 안 보냄)

다운로드 & 설치

파일 하나 받아서 실행하면 끝이에요.

1. 설치 파일 받기

이 페이지 맨 위 [지금 다운로드] 버튼을 누르면 TeacherDesk-Setup.exe가 곧바로 내려받아집니다.

2. 받은 파일 실행

다운로드 폴더의 TeacherDesk-Setup-…​.exe를 더블클릭해요.

3. “Windows의 PC 보호” 경고가 뜨면

이 앱은 값비싼 코드 서명을 하지 않아서, 처음 실행할 때 파란 경고창이 뜰 수 있어요. [추가 정보] → [실행]을 누르면 됩니다. (아래 주의 상자 참고)

4. 설치 완료 · 자동 실행

설치가 끝나면 바로 바탕화면에 위젯이 나타나요. 이후엔 컴퓨터를 켤 때 자동으로 실행됩니다.

크롬이 다운로드를 막을 때

서명하지 않은 프로그램이라 크롬이 먼저 막아서는 경우가 있어요. 아래 순서대로 하면 받아집니다.

1. “위험한 파일”이라고 뜰 때

크롬 오른쪽 위 [다운로드 아이콘] → 그 파일 옆 [점 세 개] → [계속]. 확인 창이 한 번 더 뜨니 [계속]을 두 번 누르셔야 받아집니다.

2. [계속] 버튼이 아예 없을 때

크롬 [설정] → [개인 정보 보호 및 보안] → [보안] → [표준 보호]로 바꾼 뒤 다시 받으세요. (설치가 끝나면 원래대로 되돌리셔도 됩니다.)

3. 받은 파일이 사라졌을 때

[Windows 보안] → [보호 기록] → 해당 항목 → [허용]을 누르면 되살아납니다.

4. 파란 경고창이 뜰 때

[추가 정보]를 누르면 나타나는 [실행] 버튼으로 진행하세요.

3번은 윈도우 보안이 지운 경우에만 통합니다. 보호 기록에 아무것도 없다면 크롬이 지운 것이니, 2번으로 표준 보호로 낮춘 뒤 다시 받으세요. 학교 컴퓨터에서 버튼이 회색으로 눌리지 않으면 교육청 보안 정책이라 집에서 받아 USB로 옮기는 편이 빠릅니다.

“Windows의 PC를 보호했습니다” 경고가 떠요

정상입니다. 개인이 만든 무료 프로그램이라 서명 비용을 들이지 않아서 뜨는 경고예요. [추가 정보]를 누르면 나타나는 [실행] 버튼으로 진행하세요. 백신이 막으면 잠시 허용/신뢰로 풀어 주면 됩니다.

제대로 받으신 게 맞는지 확인하고 싶다면, [추가 정보]를 눌렀을 때 나오는 게시자가 kimju.zip인지 보세요. 설치 후에는 제어판 → 프로그램 및 기능에서도 같은 이름으로 보입니다.

무엇이 근거인지 밑줄로 보여 줍니다

파란 밑줄은 메모에서 나온 대목, 보라 밑줄은 고른 초점(칩)에서 나온 대목입니다. 밑줄이 없는 부분은 AI가 이어 쓴 것이니 실제 수행과 맞는지 특히 봐 주세요. 초안마다 “메모 3곳 · 초점 2곳”처럼 개수도 나옵니다.

메모 없이 칩만 골라도 씁니다. 적을 시간이 없을 때 초점만 골라 두면 그것을 근거로 써요. 그때는 구체적인 사건·횟수·기간·역할을 만들지 않고 태도와 모습만 담담하게 적습니다. 메모도 칩도 없을 때만 막습니다.

분량은 바이트로 셉니다 — 나이스가 그렇게 세기 때문입니다(한글 1자 3바이트, 공백·마침표는 1바이트). 옆에 적힌 자수는 참고용이라, 1,114자를 써도 2,728바이트라서 한도(3,000) 안일 수 있어요. (v2.2.53~54)

작업표시줄과 겹치지 않습니다

독은 작업표시줄을 피해 그 위에 놓입니다. 화면 아래를 작업표시줄이 얼마나 쓰고 있는지 직접 읽어 그만큼 비켜서요 — 작업표시줄을 위·왼쪽·오른쪽에 두셔도, 모니터 해상도나 배율이 달라도 같습니다.

처음 설치하면 작업표시줄 자동 숨김이 켜집니다. 작업표시줄이 평소 내려가 있어 화면을 세로로 더 쓰고, 마우스를 아래로 가져가면 다시 올라와요. 불편하시면 설정 → 화면 → 작업표시줄 자동 숨김을 끄면 되고, 한 번 끄면 다시 켜지 않습니다. (v2.2.50부터)

마우스 없이 키보드로

Tab으로 옮기고 Enter(또는 Space)로 누릅니다. 독 아이콘 · 서랍 · 할 일 · D-Day · 즐겨찾기가 모두 닿습니다. 달력과 시간표는 Tab 한 번으로 표에 들어간 뒤 화살표로 칸을 옮겨요 — 칸마다 Tab을 누르면 마흔 번 넘게 눌러야 하니까요. 키보드로 옮길 때만 테두리가 보이고(마우스로 누를 때는 안 나옵니다), 창은 Esc로 닫습니다. (v2.2.48부터)

구글 캘린더 가져오기

구글 캘린더에 적어 둔 일정을 TeacherDesk 달력에 함께 띄울 수 있어요. 학교 공용 캘린더든 내 개인 일정이든 똑같이 됩니다. 캘린더를 공개로 바꾸지 않아도 돼요.

구글 캘린더에서 주소 복사

구글 캘린더를 컴퓨터 브라우저로 엽니다 (휴대폰 앱에는 이 메뉴가 없습니다). 왼쪽 캘린더 목록의 캘린더 위에 마우스를 올리면 점 세 개 단추가 나와요. 누르고 [설정 및 공유] → 그 페이지를 맨 아래까지 내려서 [캘린더 통합] → 비공개 주소(iCal 형식)를 복사해요.

설정 → [학교] 탭에 붙여넣기

학사일정 바로 아래 [구글 캘린더 가져오기]가 있어요. 이름(예: 내 일정)과 주소를 넣고 추가를 누릅니다.

바로 확인됩니다

누르는 즉시 한 번 받아 봐요. 주소가 잘못됐으면 그 자리에서 알려 주고, 제대로 되면 "일정 37건"처럼 몇 건을 가져왔는지 보여줍니다.

여러 개도 됩니다

학교 캘린더·개인 캘린더를 따로 붙여 두고 각각 켜고 끌 수 있어요. 달력에서는 파란 점으로 구분돼 보입니다.

어떤 주소를 넣어야 하나요

[캘린더 통합] 안에 비슷하게 생긴 주소가 여럿 있어서 헷갈리기 쉽습니다. 만든 사람도 세 번 만에 찾았어요. 끝이 basic.ics이고 가운데에 private-가 있는 것만 됩니다.

이것이 맞습니다
https://calendar.google.com/calendar/ical/내계정/private-xxxxxxxx/basic.ics

아래 세 가지는 모두 다른 용도라 넣어도 안 됩니다. 같은 화면에 함께 있어서 잘못 집기 쉬워요.

  • …/calendar/u/0?cid=… — 이 캘린더를 남의 구글 캘린더에 추가하는 링크입니다
  • …/calendar/embed?src=… — 웹페이지에 캘린더를 끼워 넣는 코드입니다
  • …/ical/…/public/basic.ics — .ics로 끝나지만 캘린더를 공개로 바꿔야만 작동합니다. 비공개인 채로 넣으면 앱이 "달력 파일이 아닙니다"라고 알려 줍니다

학교 공용 캘린더를 여럿이 볼 때

학교 일정을 여러 선생님이 함께 보시려면 각자 자기 주소를 받아 넣으셔야 합니다. 한 사람의 비공개 주소를 나눠 쓰면, 한 명만 새어도 전체가 뚫리고 [주소 재설정]을 누르는 순간 모두가 한꺼번에 끊깁니다.

만든 분이 공유

학교 캘린더를 만든 분이 [설정 및 공유] → [특정 사용자와 공유]에 선생님들 지메일 주소를 추가합니다.

각자 자기 주소를 받기

공유받은 선생님의 구글 캘린더 왼쪽에 그 캘린더가 나타납니다. 거기서 [설정 및 공유] → [캘린더 통합]을 열어 자기 주소를 복사해 넣습니다.
권한 설정에 따라 [캘린더 통합]이 안 보일 수 있습니다 — 그때는 만든 분께 받으셔야 해요.

공개로 바꾸는 선택지도 있습니다. 개학일·시험기간처럼 어차피 가정통신문으로 나가는 일정이라면, 만든 분이 캘린더를 공개로 설정하고 …/public/basic.ics 주소를 나눠 주면 됩니다. 감출 것이 없으니 주소가 새도 잃을 게 없어요.
다만 개인 캘린더는 절대 공개로 바꾸지 마세요. 개인 캘린더는 주소에 계정 이메일이 그대로 들어가서, 공개로 두면 이메일 주소만 아는 사람이면 누구나 일정을 전부 볼 수 있습니다.
그 주소는 비밀번호와 같습니다. 주소를 아는 사람은 로그인 없이 일정을 전부 볼 수 있어요. TeacherDesk는 이 주소를 암호로 잠가 저장하고 화면에도 가운데를 가려서 보여주지만, 남에게 주소를 보내거나 화면을 공유할 때는 조심하세요. 새 나갔다 싶으면 구글 캘린더에서 [주소 재설정]을 누르면 옛 주소가 즉시 막힙니다.
읽기만 합니다. TeacherDesk가 구글 일정을 고치거나 지우지 않아요. 그래서 달력에서도 구글 일정에는 고치기·지우기 단추가 없습니다 — 구글 캘린더에서 고치면 다음에 받아올 때 따라옵니다.
매주 화요일 같은 반복 일정도 그대로 풀어서 보여줍니다. 아주 드물게 복잡한 반복 규칙은 못 읽는데, 그럴 때는 조용히 빼놓지 않고 "못 읽은 일정 O건"이라고 알려 드려요.

AI 기능 켜기 · Gemini API 키

AI 도우미 · 생기부 초안을 쓰려면 무료 Gemini 키 하나가 필요해요.

TeacherDesk 2의 AI 기능(공지 분석, 공문서 다듬기, 생기부 초안, 손글씨·파일 읽기)은 구글의 Gemini를 사용합니다. 무료로 발급되는 API 키를 한 번만 넣어 두면 계속 쓸 수 있어요. 키는 이 컴퓨터에만 저장되고 외부로 나가지 않습니다. (키가 없어도 급식·시간표·달력 같은 나머지 기능은 그대로 됩니다 — AI 생성만 키가 필요해요.)

그런데 ‘API 키’가 뭔가요? (쉽게)

API는 프로그램끼리 부탁을 주고받는 창구예요. TeacherDesk가 구글 AI에게 “이 문장 만들어 줘”라고 부탁하는 통로죠. API 키는 그 창구에서 쓰는 나만의 출입증 — 도서관 회원카드 같은 거라고 보시면 돼요. 이 출입증이 있어야 구글이 “아, 이 선생님 요청이구나” 하고 처리해 줍니다. 그래서 처음 한 번만 내 키를 발급받아 넣어 두는 거예요. 아래 순서만 따라오시면 됩니다.

1단계 · 무료 Gemini 키 발급받기

Google AI Studio 접속

브라우저에서 아래 주소를 열고 구글 계정으로 로그인해요.

“API 키 만들기(Create API key)” 클릭

화면의 Get API key / API 키 만들기 버튼을 눌러 새 키를 만들어요.

키 복사

만들어진 긴 문자열(키)을 복사합니다. 이 키는 비밀번호처럼 남에게 보여주지 마세요.

Gemini 키 발급 주소
https://aistudio.google.com/app/apikey

2단계 · TeacherDesk에 키 넣기

설정 → AI 탭

독의 설정 → [AI] 탭으로 갑니다. 맨 위가 Gemini 키 칸이에요.

Gemini 칸에 붙여넣기

Gemini 칸에 방금 복사한 키를 Ctrl+V로 붙여넣어요.

“키 확인”으로 점검

[키 확인 (실제로 한 번 불러봅니다)] 버튼을 눌러 Gemini(AI) 확인이 뜨면 완료예요. 이제 AI 기능이 켜집니다.

키는 안전하게

API 키는 이 컴퓨터에만 저장되고 어디로도 전송되지 않아요. 다만 비밀번호처럼 다뤄서, 화면 공유나 스크린샷에 노출되지 않게 주의하세요.

키를 남에게 주거나 인터넷에 올리지 마세요 (중요)

API 키는 내 이름표가 붙은 출입증이에요. 남에게 주거나 블로그·단톡방에 올리면 그 사람이 내 키로 AI를 쓰고 그 사용량이 전부 내 계정에 쌓입니다. 무료 한도를 남이 다 써 버릴 수 있어요.

✔ 실수로 노출했다면 구글 AI 스튜디오에서 그 키를 삭제하고 새로 발급받으세요. 옛 키는 즉시 무효가 됩니다.

요금 걱정은 안 해도 돼요

Gemini 무료 한도로 우리 반은 넉넉히 써요(하루 수백 회). 다만 분당 횟수 제한이 있어서 한꺼번에 몰아 쓰면 잠깐 걸릴 수 있는데, 그땐 1분쯤 쉬었다 다시 누르면 됩니다. 이 앱은 버튼을 누를 때만 호출하고(자동 호출 없음), 설정에 “오늘 사용 n회 · 남은 횟수 약 220회”로 남은 양도 보여줘요.

바탕화면을 보면서 고르세요

[디자인] 탭 맨 위의 [🔍 바탕화면 보면서 고르기]를 누르면 설정 창이 오른쪽 위로 작게 비켜서요. 색·질감·레이아웃을 누를 때마다 바탕화면이 바로 바뀌는 게 보이니, 창을 껐다 켰다 하지 않고 바로 비교하며 고를 수 있어요. 한 번 켜 두면 다른 탭으로 옮겨도 그대로 유지되고, 설정을 닫으면 원래 크기로 돌아옵니다.

위젯을 원하는 자리에 직접 놓으세요 — 버튼 하나면 바로 편집됩니다

설정 → [디자인] 탭 맨 아래 “직접 배치”의 [위젯 위치·크기 직접 정하기]를 누르면, 설정 창이 저절로 닫히면서 곧바로 편집 모드로 들어갑니다. 따로 켜고 끄는 스위치를 찾을 필요가 없어요.

편집 모드에서는 화면 위에 “위젯 배치 중” 띠가 뜨고, 이렇게 하시면 됩니다 —

  • 카드를 마우스로 끌어 원하는 자리로 옮기고
  • 오른쪽 아래 모서리를 잡아 크기를 바꾸고
  • 안 쓰는 카드는 왼쪽 위 ✕로 빼면 됩니다 (다시 켜기는 [위젯] 탭에서)

다 하셨으면 띠의 [완료]를 누르거나 Esc를 누르면 그대로 저장됩니다. 마음에 안 들면 띠의 [원래대로], 또는 [디자인] 탭에 생기는 [원래 배치로]를 눌러 언제든 기본 배치로 되돌릴 수 있어요 — 되돌릴 수 있으니 편하게 만져 보세요.

레이아웃·밀도 설정과 별개로 동작하니, 정해진 배치 10가지가 마음에 안 드실 때 쓰시면 됩니다.

[지금 자리 그대로 굳히기]는 뭐가 다른가요? — 평소 위젯 자리는 레이아웃 규칙이 정해서, 설정을 바꾸면 자리가 다시 계산돼 움직일 수 있어요. 이 버튼은 지금 보이는 배치를 그대로 좌표로 도장 찍습니다 — 옮길 생각은 없고 이대로 고정만 하고 싶을 때 쓰세요. (편집 모드에 들어가면 이 도장이 저절로 찍히므로, 이미 직접 배치 중이면 버튼이 안 보입니다.)

🖥️ 노트북에 모니터를 붙였다 떼시나요? (v3.0 · v3.10에서 더 정확해짐) — 배치는 화면 구성마다 따로 기억됩니다. 노트북만 쓸 때와 모니터를 붙였을 때가 각각 저장되어, 선을 뺐다 꽂아도 그 구성의 배치가 저절로 돌아옵니다. 버튼을 누를 일도 없어요 — 자동입니다. v3.10부터는 모니터 대수까지 함께 기억해서, 두 구성의 해상도가 같아도 서로 섞이지 않습니다.

[다른 화면 구성에서 복사]는 언제 쓰나요? — 그 구성을 처음 만났을 때 한 번입니다. 예를 들어 두 모니터에서 배치를 공들여 잡아 두었는데 HDMI를 뽑아 처음으로 한 모니터가 되면, 한 모니터 쪽에는 저장된 배치가 없어 기본 배치가 나옵니다. 이때 처음부터 다시 끌지 말고 이 버튼을 누르세요 — 두 모니터에서 잡아 둔 배치를 화면 크기에 비율로 맞춰 가져옵니다. 시계가 오른쪽 위였으면 여기서도 오른쪽 위에, 축소판으로요. 어긋난 한두 개만 다듬으면 되고, 한 번 다듬어 두면 그다음부터는 이 구성도 저절로 돌아오는 쪽이 됩니다. (다른 구성에 저장된 배치가 있을 때만 버튼이 나타납니다.)

위젯을 켰는데 안 보인다면

레이아웃마다 담을 수 있는 자리가 정해져 있어요. 자리가 모자라면 그 위젯은 화면에 못 올라오고, [위젯] 탭에 “지금 레이아웃엔 자리가 없어요”라고 표시됩니다. 다른 레이아웃으로 바꾸거나, 덜 쓰는 위젯을 꺼 주세요. (특히 간결 레이아웃과 앨범을 켠 경우에 자주 생겨요.)

독(Dock)은 화면의 실행 막대예요. [독] 탭에서 표시할 기능과 순서를 바꾸고, 자주 쓰는 프로그램 바로가기를 끼워 넣을 수 있어요. 아이콘은 그림↔기호↔글자로 바꿔집니다. 프로그램 바로가기는 원래 아이콘을 또렷하게 가져와 놓아요.

독을 안 쓰실 수도 있어요 (v2.9.19) — [독] 탭의 독 위치에서 안 씀을 고르면 독이 사라지고 그 자리까지 위젯이 넓게 씁니다. 위젯만 두고 깔끔하게 쓰고 싶을 때 좋아요. 아이콘 순서·모양은 그대로 남아 있어서 다시 켜면 예전 그대로 돌아옵니다.
다만 독으로 열던 AI 비서 · 생기부 · 전광판 · 즐겨찾기 · 명렬 · 내선번호와 서랍 · 프로그램 바로가기도 함께 사라지니 참고하세요. 설정은 화면 오른쪽 아래 트레이 아이콘을 우클릭해 여시면 됩니다.

기능 둘러보기

위젯과 독에 담긴 기능들을 한눈에.

오늘의 비서

아침에 앱을 켜면 오늘 것을 한 자리에 모아 보여드립니다 — 오늘 할 일, 오늘 수업, 급식, 챙길 것(오늘 일정과 이레 안으로 다가온 D-Day). 자료를 새로 만드는 게 아니라 이미 앱에 있는 것을 모아 보여줄 뿐이라, Gemini 키가 없어도 인터넷이 없어도 뜹니다.
하루에 한 번만 뜹니다 — 일하시는 도중에 갑자기 생기지 않아요. 그리고 보여드릴 것이 하나도 없으면 아예 뜨지 않습니다. 아직 아무것도 안 적으셨다면 빈 창을 닫으실 일이 없죠.
맨 아래 인사말은 200가지가 들어 있고 날짜로 골라 씁니다 — 같은 날엔 몇 번을 켜도 같은 말이고, 한 바퀴 도는 데 꼬박 1년입니다. 끄고 켜기는 설정 → 위젯 맨 위. 팝업 안 [다시 안 보기]로도 끕니다. (v3.9.0)

빠른 입력 — 한 줄로 적으면 알아서 갈라 넣습니다

독 → AI 도우미 → 빠른 입력. 한 줄로 적으면 할 일 · 달력 일정 · D-Day · 메모 가운데 어디에 넣을지 갈라서 보여드리고, 확인하신 뒤에 저장합니다.
예를 들어 8/3~8/8 생기부 점검 할일 등록, 9/2 방학 디데이 등록이라고 적으면 할 일(마감 8/8) · 달력 일정(8/3~8/8) · D-Day(9/2, D-5) 셋으로 갈라집니다. 한 문장이 여러 곳으로 동시에 갑니다.
「내일」·「다음주 월요일」처럼 적으셔도 됩니다. 다만 AI가 날짜를 잘못 셀 때가 있어 확인 화면에 실제 날짜를 요일까지 적어 두었습니다 — 틀렸으면 저장 전에 눈에 띕니다. 넣을 곳이 엉뚱하면 그 배지를 눌러 바꾸세요. (v3.9.0)

오늘 시간표

주간 시간표는 칸이 작아 잘 안 읽히는데, 아침에 확인하는 건 오늘치뿐이죠. 오늘 하루만 세로로 크게 폅니다. 설정 → 위젯 → 오늘 시간표를 켜세요(기본 꺼짐). 자료를 새로 받지 않고 이미 받아 둔 학기 시간표에서 오늘 요일만 꺼내 씁니다. 칸을 눌러 적고 우클릭으로 색칠하는 것이 주간과 똑같고, 한쪽에 적으면 다른 쪽에도 바로 반영돼요. 주말에는 “오늘은 수업이 없어요”가 뜨고, 자정이 지나면 저절로 다음 날로 바뀝니다. (v2.9.0)

할 일에 분류 붙이기

할 일이 쌓이면 종류별로 보고 싶어지죠. 수업 · 담임 · 행정 · 행사 · 연구 · 기안 · 품의 일곱 가지를 미리 넣어 두었습니다.
🔴 이름과 색은 바꾸셔도 됩니다 — 지우고 새로 더하셔도 되고요. 학교마다 부르는 말이 다르니까요. 설정 → [위젯] 탭에서 고칩니다.
넓은 화면에서는 할 일 앞에 「수업」처럼 글자로 붙고, 좁은 카드에서는 색 점으로 접힙니다 — 안 접으면 할 일 제목이 한 글자만 남거든요. 점에 마우스를 올리면 이름이 뜹니다.
이미 적어 둔 할 일에 붙이려면 제목 옆 [전체]를 열고 줄 끝 ✎에서 고르세요.
제목 옆 [전체]를 누르면 위에 분류 칩이 줄지어 나옵니다. 눌러서 그 분류만 볼 수 있어요.
⚠️ 분류를 지워도 할 일은 안 지워집니다 — 그 할 일이 «분류 없음»으로 돌아갈 뿐이고, 4초 안에 되돌릴 수 있습니다.
달력에서 적으실 때는 날짜를 눌러 [할 일] 탭으로 가면 분류 줄이 나옵니다 — 고르고 적으면 그대로 저장돼요. 이어서 적을 때는 고른 분류가 그대로 남습니다.
달력 칸에서도 마찬가지입니다 — 칸이 넉넉하면 「수업」처럼 이름으로, 좁으면 점으로 나옵니다. 🔴 칸 폭은 달력 크기가 아니라 「배치」가 정합니다 — [디자인] 탭의 달력 크기(보통·크게·아주 크게)는 글자 크기를 바꾸는 것이라 키워도 칸은 안 넓어져요. 이름이 안 보이시면 배치를 바꿔 보세요 (기본·좌우 분할·캘린더 중심·달력 전면에서는 이름이 나오고, 칸이 가장 좁은 와이드에서는 점으로 남습니다). (v3.14.3)

쪽지 글을 다 보이게

메모(쪽지)는 여덟 줄까지만 보이고 나머지는 접힙니다 — 긴 쪽지 한 장이 카드를 다 먹으면 다른 쪽지가 안 보이니까요.
다 보고 싶으시면 설정 → [위젯] 탭 → 메모 아래 「쪽지 글 다 보이기」를 켜세요. 넘치는 글은 쪽지 칸을 아래로 밀어 보시면 됩니다. (v3.14)

일정에 알림 걸기

달력에서 날짜를 누르면 ⏰ 시각을 정하고 언제 알릴지를 고를 수 있어요 — 안 함 / 정각 / 5분 전 / 10분 전 / 30분 전. 그 시각이 되면 윈도우 알림으로 알려 드리고, 누를 때까지 화면에 남습니다. 수업 들어가기 전에 뜬 알림이 5초 만에 사라지면 못 보니까요.
🔴 기본은 «안 함»입니다 — 고르신 일정만 울려요. 이미 적어 둔 일정은 그 줄의 ⏰로 나중에 붙이거나 고칩니다. 지난 시각에 걸면 «이미 지났습니다»라고 알려 드리고, 여러 날 이어지는 일정은 시작한 날에만 울립니다. 앱이 꺼져 있던 사이에 지나간 알림은 뒤늦게 뜨지 않아요. (v3.13)

수업이 시작되면 알려 드립니다

설정 → [시간표] 맨 위에서 켜세요. 내 수업이 시작될 때 「1교시 체육 · 수업 시작 시간입니다. 화이팅입니다!」처럼 알려 드립니다. 시작 시각에 딱 맞춰 / 5분 전 / 10분 전 중에 고르실 수 있어요.
🔴 기본은 꺼져 있습니다 — 하루 예닐곱 번 울리는 알림이라 쓰실 분만 켜는 편이 낫습니다. 시간표에 과목을 적어 둔 교시만 울리고(빈 칸은 내 수업이 아니니까요), 토·일은 [주말 수업] 설정을 따릅니다. (v3.13)

창을 아무 데나 눌러 닫기

날짜 창·날씨 창처럼 위젯에서 펼쳐 본 창을, 이제 ✕를 찾지 않아도 됩니다. 바탕화면이나 다른 위젯을 누르면 저절로 닫혀요. 창 안을 누르는 것은 그대로라 고르는 도중에 사라지지 않습니다. (v3.13)

지우기 전에 한 번 여쭙니다

되돌리기는 그대로 있어요 — 확인을 누르고 나서 아차 싶으면 4초 안에 되돌릴 수 있습니다. 묻는 것과 되돌리는 것은 서로를 대신하지 않으니까요. (v3.13)

적어 넣은 것을 위아래로 옮기기

쌓아 놓고 보면 순서가 마음에 안 들 때가 있죠. 항목에 마우스를 올리면 줄 끝에 ▲▼가 나타납니다. 눌러서 그 자리에서 위아래로 옮기세요. 할 일 · D-Day · 달력에 적은 일정 · 메모(쪽지) 네 곳 모두 되고, 제목 옆 [전체]로 연 큰 창에서도 똑같습니다.
할 일과 D-Day는 원래 저절로 줄을 섭니다 — 마감이 가까운 순, 날짜가 가까운 순으로요. 그래서 손으로 옮기면 「내가 정한 순서」로 바뀝니다. 말풍선으로 알려 드리고, 제목 옆에 ✋ 내 순서가 붙어요. 그걸 누르면 원래 정렬로 돌아갑니다. 새로 적은 것은 맨 아래에 붙고, 끝낸 할 일은 그래도 아래로 내려갑니다 — 위에서부터 읽는 것만으로 남은 일이 보이도록요.
달력에 적은 일정은 그 날 안에서만, 쪽지는 그 카드 안에서만 움직입니다. 나이스 학사일정과 구글 캘린더 일정은 남의 자료라 자리를 바꾸지 않아요. (v3.11.0)

기본은 꺼져 있어요 — 칸이 늘어나면 그만큼 좁아져 과목 글자가 먼저 잘리거든요. 쓰시는 분만 켜는 편이 낫습니다. 껐다고 적어 둔 과목이 지워지지는 않습니다 — 다시 켜면 그대로 나옵니다. (v3.11.0)

할 일이 달력에도 함께

달력 칸이 좁으면 글자 대신 점으로 줄여 표시하고, 날짜를 누르면 그 날 것이 모두 펼쳐집니다. 마감일이 없는 할 일은 어느 날짜에 놓을지 알 수 없으니 달력에는 안 나와요.
보고 싶지 않으시면 달력 오른쪽 위 ⚙ → [할 일]로 끄면 됩니다. 이전 판부터 쓰시던 분은 예전 설정이 그대로이니, 안 보이면 거기서 켜 주세요. (v3.11.0)

나의 시간표

진도 (v2.9.17에서 크게 바뀜)

오늘 들어가는 수업이 주간 시간표에서 저절로 줄을 섭니다 — 반을 고를 필요가 없어요. 수업이 끝나면 그 줄을 한 번 누르기만 하면 됩니다. 차시는 지난 시간 +1로 저절로 이어지고 창은 뜨지 않아요. 비가 와서 이론으로 때운 시간은 휴강으로 두면 차시를 먹지 않습니다.

수업 내용은 학년이 함께 씁니다 — 같은 학년은 같은 진도를 나가지요. 그래서 내용은 반이 아니라 차시에 붙어 있습니다. 1학년 4차시 = “배구 서브”를 한 번만 적으면 1반이 하든 3반이 다음 주에 하든 같은 내용을 함께 봅니다. 다른 반에 옮겨 적거나 “이 반에도 넣을까요?” 하고 물을 일이 없어요 — 처음부터 하나를 같이 보는 것이니까요.

내용은 언제 적나 — 미리 안 적어 두셔도 됩니다. 그 학년에서 처음 그 차시를 하는 반에서만 “몇 차시에 무엇을 하셨어요?” 하고 한 줄 묻고, 그 뒤로는 묻지 않습니다. 학기 초에 1차시부터 죽 적어 두면 수업 뒤엔 누르기만 하면 되고요. 둘을 섞어 쓰셔도 됩니다.

[전체] — 학년 진도표 — 왼쪽은 세로 날짜 · 가로 반 격자로, 칸마다 차시(크게)와 교시(작게)가 보입니다. 오른쪽은 차시별 수업 내용 목록이고요. 격자에서 4를 보고 오른쪽에서 그게 “서브”인 걸 바로 확인하는 식입니다. [1학년] [2학년] 탭으로 학년을 고르고 좌우 화살표로 주를 넘깁니다. 수업 없는 칸은 빗금, 오늘 줄은 띠로 표시되고, 아직 오지 않은 날도 미리 적어 둘 수 있어요(점선).

반 이름을 누르면 그 반만 (v2.9.17) — 격자 머리글의 1-1을 누르면 그 반이 언제 몇 차시를 했는지 차시순으로 죽 펼쳐집니다. 휴강도 남고, 아직 안 한 차시까지 점선으로 이어 붙어 “무엇이 남았나”가 보여요. [전체로] 단추로 격자에 돌아옵니다.

고치기 — 적은 칸을 다시 누르면 창이 뜹니다. 차시를 − +로 옮기거나, 휴강으로 두거나, 그 반만의 한 줄(예: “비 · 이론”)을 답니다. 여기서 차시 내용을 고치면 그 학년 모든 반이 함께 바뀝니다.

안 보이면 배치를 확인하세요 (v2.9.10) — 진도는 아홉 배치에서 쓸 수 있습니다. 와이드 배치만 카드가 이미 꽉 차 자리를 못 만들었어요(넣으면 시계·날씨가 잘립니다). 그 배치에서는 [위젯] 탭에 “지금 레이아웃엔 자리가 없어요”로 표시되니, 다른 배치로 바꿔 주세요. 진도를 끄면 그 자리를 시간표가 도로 가져가므로, 안 쓰시는 분 화면은 예전 그대로입니다.

쓰시던 기록은 그대로입니다 — 예전에 칸마다 적어 두신 단원·메모는 처음 열 때 학년 차시 내용으로 옮겨집니다(원래 기록은 지우지 않습니다).

학생 누가기록 (v2.9.10)

명렬에서 학생 이름 옆 📝를 누르면 그 학생의 활동기록과 상담기록을 한 줄씩 적어 둘 수 있습니다. 수업에서 본 것을 그때그때 남겨 두면, 생기부를 쓸 때 관찰 메모 칸 위의 [📝 평소 기록 불러오기]로 한 번에 들어와요 — 12월에 기억으로 쥐어짤 일이 줄어듭니다. 날짜는 자동으로 붙고 고칠 수 있으며, 잘못 지우면 4초 안에 되돌립니다. 불러올 때는 적어 둔 내용만 들어가고(생기부 문장에 날짜를 쓸 일이 없으니까요), 시기가 필요할 때만 [날짜도 함께]를 켜세요. 학기말에는 설정 → [데이터] → 엑셀로 내보내기로 반마다 시트가 나옵니다.

상담기록은 화면에서만 봅니다 — 가정사·교우관계처럼 생기부에 옮겨서는 안 되는 내용이 섞이기 때문입니다. 불러오기에도, AI에도 들어가지 않아요. 엑셀에는 함께 나가지만 구분 열로 갈라 적고 옅은 보라로 칠해 두니, 누구에게 넘길 파일이라면 그 줄만 지우면 됩니다.

달력 ⚙ 와 초과근무 (v2.9.10)

초과근무를 달마다 쌓아 줍니다 — 달력에서 날짜를 누른 뒤 [초과] 칸에 그 날 시간을 적으세요. 1h·2h·4h 단추는 누르는 즉시 저장되고, 직접 적으면 30분 단위까지 됩니다(4.5 = 4시간 30분). 적어 둔 날은 칸 오른쪽 위에 4h처럼 붙고 그 달 합계가 저절로 쌓여요. 합계를 어디에 적을지도 ⚙에서 고릅니다 — 제목 옆 / 달력 아래 / 안 보임.

수기 입력 — 교시마다 시작·끝 시각을 직접 적습니다. 쉬는 시간이 교시마다 다른 학교(1교시 뒤 15분, 2교시 뒤 10분처럼)는 자동 계산으로는 맞출 수가 없어요. 그런 학교는 여기서 정합니다.
수기로 바꾸면 지금 설정으로 계산한 값이 먼저 채워집니다 — 처음부터 다 적을 필요 없이 어긋난 줄만 고치면 됩니다. 교시를 더하거나 빼고, 점심 줄도 원하는 자리에 넣을 수 있어요. 교시 번호는 줄 순서대로 저절로 다시 매겨집니다.
적는 도중이라 비어 있거나 끝이 시작보다 앞선 줄은 그 줄만 건너뜁니다 — 고치는 중에도 시간표가 깨지지 않아요. 시각은 24시간 형식으로 적습니다(오후 1시 = 13:00). 교시는 15교시까지 됩니다.

‘지금 이 시간’에 뜰 말 고치기

설정 [시간표] 탭 아래쪽에서 수업 전 · 공강 · 퇴근 뒤에 뜰 문구를 직접 쓸 수 있습니다. 비워 두면 기본 문구가 나와요. “일과 종료 · 퇴근하세요!”가 교실 화면에 뜨는 게 부담스러우면 여기서 바꾸시면 됩니다.

서랍에 파일 개수 안 보이게

독의 서랍에 든 파일 수가 숫자로 뜨는데, 설정 [독] 탭 → 서랍에 파일 개수 보이기를 끄면 그냥 폴더로만 보입니다. 안에 든 파일 미리보기는 그대로 남아요.

담임반 출결

독의 ✓ 출결에서 날짜별로 찍어 둡니다. NEIS와 같은 뼈대(조회·1~N교시·종례 칸, 구분×종류, 사유)라 옮겨 적을 때 눈이 그대로 따라가요. 종류를 고르면 교시가 저절로 채워집니다(결석은 하루 전부, 지각은 조회+1교시…). 설정 [학교] 탭에 담임 학년·반을 넣어야 나오고, 교과로만 들어가는 반이면 비워 두세요. NEIS 정식 입력을 대신하지는 않습니다 — 조회 시간에 빠르게 적어 두는 기록이에요.

급식 · 날씨 · 시간표

학교 기준 오늘 급식, 지역 날씨·미세먼지, 주간 시간표(칸을 눌러 입력, [시간표] 탭에서 글자 크기 3단계 선택). 급식은 카드 제목 옆 날짜 화살표로 다른 날도 보고, 설정 [위젯] 탭에서 조식·중식·석식 중 볼 끼니만 고릅니다 — 세 끼가 다 뜨면 좁은 카드에서 중식이 잘려 안 보였거든요. 두 끼 이상 고르면 위아래로 쌓지 않고 옆으로 나란히 놓입니다.

전체 시간표 — 학기 기준 과목별 · 교사별

시간표 카드 제목 옆 [전체 시간표] 버튼을 누르면 탭이 셋 뜹니다(학교 등록 필요, NEIS 제공 학교만).
과목별 — 이번 학기 정규 시간표입니다. 학기 전체를 받아 요일·교시마다 가장 자주 하는 과목으로 그리기 때문에, 이번 주에 휴업일이 껴 있어도 표가 흔들리지 않아요(한 번 보면 그 학기 내내 그대로). 과목을 고르면 월~금 × 교시 격자에 그 과목을 하는 반이 모두 뜨고, 같은 시간에 두 반 이상이면 빨갛게 표시돼요.
과목은 여러 개를 함께 볼 수 있습니다 — 칩을 누를 때마다 켜지고 꺼집니다. 중학교 체육 선생님은 체육 + 스포츠클럽을 같이 봐야 하죠(둘 다 강당·운동장을 씁니다). 하나만 보면 정작 부딪히는 시간을 못 찾습니다. 과학 + 정보(과학실·컴퓨터실), 음악 + 합주실기처럼 같은 특별실을 쓰는 조합이면 무엇이든 됩니다. 칸마다 어느 과목인지 붙고, 겹침 판정도 고른 과목을 합쳐서 합니다.
교사별 — 적어 둔 교사 이름으로 묶어 교사별 주간 시간표처럼 봅니다. 학급별(오늘) — 이름 그대로 오늘 기준이라 휴업·행사가 반영된 그날 시간표가 나옵니다.
학기 중에 시간표가 바뀐 칸은 점선으로 표시하고, 마우스를 올리면 몇 주 중 몇 주였는지 보여줍니다. 자료는 학기당 한 번만 받고, 바뀌었으면 창 위의 [↻ 새로고침]으로 다시 받습니다.
NEIS 키가 없어 일부 학급만 왔으면 몇 개 중 몇 개인지 숫자로 알려주고, 바로 [학교] 탭으로 이동하는 버튼도 함께 떠요.

학사일정 고치기 · 지우기

학사일정 카드에서 줄을 클릭하면 날짜·이름을 고치고, 우클릭하면 지웁니다(4초 안에 [되돌리기]). 제목 옆 ＋로 새 일정을 넣어요. 달력에서도 날짜를 눌러 나온 창의 학사일정 줄에 ✎·✕가 있습니다.
학교가 NEIS에 올린 일정을 고쳐도 다음 새로고침에 되살아나지 않습니다 — 학교가 잘못 올렸거나 이름이 길 때 내 화면에서만 정리해 둘 수 있어요. 원래 이름·날짜로 되돌리면 고친 기록도 함께 지워집니다.

서랍 = 진짜 폴더

독의 서랍은 바탕화면의 실제 폴더예요. 파일을 끌어 넣으면 실제로 정리됩니다. 폴더를 실수로 지웠다면 서랍을 한 번 누르면 다시 만들어집니다. 비어 있을 때는 [폴더 열기]로 바로 열어 파일을 넣을 수 있어요.

할 일 · D-Day · 메모

할 일 체크, 시험·행사 D-Day, 바로 적는 메모. 할 일은 오른쪽 클릭으로 삭제하고, 잘못 지웠으면 바로 뜨는 [되돌리기]로 살립니다.

시간표 칸 색칠

시간표 칸을 우클릭하면 색을 칠할 수 있어요(10가지). 반별 자동 색은 “무슨 반인가”를 보여 주는데, 겸무·전담·회의처럼 반으로 갈리지 않는 시간은 거기 묻힙니다. 그런 칸을 손으로 칠해 두면 눈에 띄어요. 칠한 색이 자동 색보다 앞섭니다. 지울 때는 같은 창의 [색 지우기].

프로그램 바로가기

앨범 — 바탕화면 사진 액자

가족사진처럼 늘 보고 싶은 사진을 바탕화면 액자로 띄웁니다. 설정 → [화면] 탭에서 사진을 고르세요(기본 꺼짐).
담는 방법이 셋입니다 — 꽉 채우기는 가장자리가 잘릴 수 있고, 전체 보기는 여백이 생기며, 직접 맞추기를 고르면 사진 위 네모를 끌어 액자에 담을 부분을 직접 정합니다(확대도 됩니다). 액자 크기는 [위젯] 탭의 앨범 크기로 바꿉니다.
보여주기 전용이라 사진을 끌어다 놓아도 바뀌지 않습니다. 앨범을 켜면 배치에 자리가 모자라 다른 위젯이 안 올라올 수 있는데, 그때는 [위젯] 탭에 “지금 레이아웃엔 자리가 없어요”로 표시됩니다.

메모 카드를 넷까지 · 이름 붙이기

제목을 눌러 이름을 붙입니다 — 설정 [위젯] 탭 목록에도 그 이름으로 나오니 어느 것이 어느 것인지 헷갈리지 않아요.
쪽지마다 바탕색·글자색·글자 크기·굵기를 따로 고릅니다. 칠판 같은 어두운 질감에서는 글자색이 저절로 대비를 맞춥니다.
⚠️ 메모 2·3·4는 배치표에 자리가 없습니다 — 켜면 그 자리에서 알려 드리고, [직접 배치로 두기] 한 번이면 빈 곳에 앉습니다.

컴시간알리미에서 시간표 받기

설정 → [학교] 탭 → 시간표 출처에서 컴시간알리미를 고르면 주간 시간표를 거기서 받아옵니다. 나이스로 되돌릴 수도 있어요.
이번 주 교체·대체 수업이 그대로 들어옵니다 — 원래 수업은 줄을 그어 함께 보여 주고, 아침 8시·낮 1시에 저절로 새로 받습니다.
컴시간을 고르면 [전체 시간표]도 함께 바뀌고 교사 이름까지 자동으로 채워집니다. 나이스로 되돌려도 손으로 적어 두신 교사 이름은 그대로 남습니다.
🔴 학교를 찾을 때는 이름을 줄여서 치세요 — 원일중학교로는 한 곳뿐이지만 원일중으로는 세 곳이 나옵니다. 학교마다 등록된 이름이 제각각이라 짧게 치는 편이 잘 찾힙니다.

여러 날 이어지는 일정

수련회·시험기간처럼 며칠에 걸친 일정을 달력에 넣습니다. 날짜 칸을 눌러 일정을 적을 때 「여러 날 이어지는 일정인가요?」가 함께 뜨고, 1박2일 · 2박3일 · 5일 · 1주일 단추로 한 번에 잡습니다.
넣으면 이어지는 날마다 함께 보입니다. 다만 지우거나 고치는 것은 시작한 날에서 하세요 — 뒤에 보이는 것은 이어져 보이는 것일 뿐입니다.

단축키와 트레이 아이콘

Ctrl + Space — 빠른 찾기(학생·내선·할 일·일정·파일·설정을 한 칸에서 찾습니다). 한/영 전환과 겹치는 컴퓨터에서는 Ctrl + Alt + Space로 저절로 잡힙니다.

전체 가리기 — 학생이 왔을 때

화면 오른쪽 위 단추를 누르면 위젯도 독도 통째로 사라지고 그 단추만 남습니다. 다시 누르면 그대로 돌아와요.
끄는 것이 아니라 가리는 것이라 적어 두신 것은 하나도 건드리지 않습니다. 학생이 오거나 화면을 잠깐 비워야 할 때 쓰세요. 단추를 아예 안 보이게 하려면 설정에서 [오른쪽 위에 가리기 단추 두기]를 끄면 됩니다.

위젯이 놓일 영역 정하기

직접 지정을 고르면 가로·세로 크기를 숫자로 넣어 원하는 만큼만 씁니다. 바탕화면 아이콘 자리를 비워 두고 싶을 때 좋아요.
영역을 좁게 잡으면 아래 독도 같이 줄어 한 줄에 들어옵니다(아이콘이 아주 많으면 두 줄로 접힙니다).

요일마다 다른 시정 · 여러 번의 점심

수요일만 단축수업인 학교가 많죠. 요일마다 표를 다 적을 필요는 없습니다 — 기본 하나를 적어 두고 다른 요일만 따로 적으면 됩니다. 교시 시각 표 위의 기본 · 월 · 화 · 수 · 목 · 금 탭에서 고르세요.

익명으로 갑니다 — 학생 자료는 함께 가지 않아요. ⚠️ 다만 이 칸에 학생 이름은 적지 마세요. 적으면 적으신 그대로 전송됩니다.
같은 탭에 공지도 있습니다 — 새로 생긴 기능과 고친 내용이 여기 올라오고, 새 버전이 나오면 오른쪽 아래 알림으로도 알려 드립니다.
맨 아래 익명 사용 집계는 하루 한 번 무작위 번호와 버전만 보내는 것으로, 꺼도 모든 기능이 그대로 동작합니다.

생기부 도우미 — 분량은 "표현"으로 채웁니다

메모가 짧아도 칸은 채웁니다. 다만 없는 역할(반장 등)이나 일화를 지어내는 대신 같은 사실을 다른 표현·다른 각도로 풀어 채웁니다. 메모 한 줄이어도 한도의 90% 안팎까지 씁니다(2026-08-15 개선 — 예전에는 75%쯤에서 멈췄습니다). 그래서 메모가 짧으면 같은 이야기가 돌고 도는 느낌이 들 수 있어요 — 장면을 한두 개만 더 적으시면 훨씬 알찬 글이 됩니다. 길게 쓰기 어려우면 왼쪽 초점 칩에서 부각할 점을 골라 주세요 — 고른 초점은 메모에 근거가 있을 때만 글에 드러납니다. 세특은 담당 과목에 맞는 어휘가 맨 위에 따로 나옵니다(체육이면 전술 이해·페어플레이, 국어면 고쳐쓰기·근거 제시). 고른 칩은 과목마다 따로 기억합니다.

그래도 AI가 없는 말을 넣으면, 초안을 고치는 칸 아래에 메모와 대조한 빨간 경고가 뜹니다 — 메모에 없던 역할·직책(반장 등), 횟수·기간(3회 등), 변화 과정(‘초기에는 ~했으나 점차’, ‘거듭될수록’)을 짚어 줍니다. 다만 낱말이 아니라 뜻으로 봅니다 — 메모에 “2학기 들어 손 드는 횟수 늘어남”처럼 변화가 적혀 있으면 초안에 ‘점차’가 있어도 경고하지 않습니다(2026-08-16 개선). AI를 다시 부르지 않아 키·사용량과 상관없이 늘 동작합니다.

특수교육 기본 교육과정을 따르는 학생은 일상생활 활동상황을 쓰실 수 있습니다 — 기재요령(제13조의2)의 의사소통 · 자립생활 · 신체활동 · 여가활동 · 생활적응 다섯 영역을 합쳐 1,000자입니다(나이스도 특기사항 한 칸이라, 한 화면에서 영역별 칩을 골라 하나의 글로 씁니다). ‘도움의 정도’ 칩(전신 도움 → 부분 도움 → 시범 → 몸짓 안내 → 말로 안내 → 스스로 시작)이 따로 있어, “무엇을 했나”가 아니라 “어느 만큼의 도움으로 했나”가 드러나게 씁니다 — 이 항목이 요구하는 ‘진보’가 여기서 드러납니다.

저장한 글은 반별 탭으로 나눠 봅니다. 엑셀로 내보내면 반마다 시트가 따로 생기고, 한 줄이 학생 한 명(학년 · 반 · 번호 · 이름 · 행동특성 · 세특(과목별) …)이라 나이스에 옮겨 적기 좋습니다.

위젯 모드 · 화면 배치

바탕화면 아이콘도 쓰고, 위젯도 쓰는 방법.

설정 → 화면 탭에서 배치 방식을 고를 수 있어요.

모드이렇게 동작해요
위젯 (추천)위젯만 남기고 나머지는 바탕화면이 그대로 보여요. 빈 곳의 아이콘은 평소처럼 클릭되고, 위젯은 눌러서 쓸 수 있어요.
일반 창화면 전체를 채우는 창으로 띄워요. 위젯에만 집중할 때 좋아요.
  • 글자를 적을 때는 창이 잠깐 깨어납니다 (v2.9.11) — 위젯 모드는 창을 바탕화면 맨 아래에 깨우지 않고 둡니다(그래야 아이콘을 가리지 않아요). 그런데 키보드는 창이 깨어 있어야 들어옵니다. 그래서 예전에는 진도·메모 같은 곳에 글자만 안 써졌어요(팝업은 열리고 단추는 눌리는데). 이제 입력칸을 누르면 저절로 깨어나고, 다 적고 바깥을 누르면 제자리로 돌아갑니다.
  • 앞으로 보기 — Ctrl+Alt+D를 누르면 위젯이 잠깐 앞으로 나와요(다시 누르면 바탕화면으로).
  • 독도 화면 영역에 맞춰 작아집니다 — 위젯 영역을 오른쪽 절반처럼 좁게 잡으면 아래 독도 같이 줄어 한 줄에 들어옵니다(아이콘이 아주 많으면 두 줄로 접힙니다).
  • 표시할 모니터 — 모니터가 여러 대면 설정 → 화면 탭에서 주/왼쪽/오른쪽 화면을 고를 수 있어요.
  • 윈도우 시작 시 자동 실행 — 설정 → 화면 탭에서 켜고 끌 수 있어요.
  • 설정 백업 — 설정 → 데이터 탭의 설정 내보내기/가져오기로 다른 PC에 그대로 옮길 수 있어요.
  • 저장은 이렇게 지켜집니다 — 저장할 때마다 직전 내용을 백업 파일로 함께 남깁니다(store.backup.json). 백신이 파일을 잠깐 붙잡아 저장이 튕겨도 몇 번 더 시도해요.
  • 설정 파일을 못 읽었을 때 — 프로그램은 기본값으로 열리지만, 못 읽은 파일을 사본으로 떠 둡니다(store.broken-날짜시각.json). 켤 때 알림으로 알려 드리니 그 파일을 지우지 마세요 — 원래 자료가 그대로 들어 있습니다.
트레이가 뭐예요?

화면 오른쪽 아래, 시계 근처의 작은 아이콘 모음이에요. TeacherDesk 아이콘을 오른쪽 클릭하면 새로고침 · 앞으로 보기 · 설정 열기 · 종료가 나옵니다. 나머지 설정은 모두 설정 창에 모여 있어요.

업무포털 자동 로그인

컴퓨터를 켜면 업무포털에 로그인된 창을 열어 둡니다. 쓰실 분만 켜세요.

설정 → [업무포털] 탭에서 켭니다. 켜 두면 컴퓨터를 켠 뒤 크롬(또는 엣지) 창이 하나 열리고, 인증서 로그인 → 비밀번호 입력까지 대신 해 둡니다. 끝나면 그 창은 그대로 두니 바로 업무 보시면 됩니다. 기본은 꺼져 있습니다.

1. 켜기

설정 → [업무포털] → 맨 위 스위치를 켭니다.

2. 어디에 로그인할지

나이스 또는 K-에듀파인을 고릅니다.

3. 교육청 · 인증서

교육청을 고르고, 인증서 아이디와 인증서 비밀번호를 넣습니다. 브라우저(크롬·엣지)도 고릅니다. 전남·광주는 포털이 합쳐져 전남광주통합특별시교육청 한 줄로 나옵니다.

4. 확인

[지금 한 번 해 보기]를 눌러 정말 되는지 봅니다. 잘 되면 다음부터는 컴퓨터를 켤 때 알아서 합니다.

5. 바탕화면 버튼 (v2.9.6)

설정 → [위젯] → 업무포털 로그인을 켜면(기본 꺼짐) 바탕화면에 버튼 카드가 하나 붙습니다. 필요할 때 눌러서 언제든 열 수 있어요.

자동 실행이 부담스러우면 버튼만 쓰세요 (v2.9.6)

맨 위 스위치를 꺼 두어도 바탕화면 버튼은 그대로 동작합니다. 아침마다 창이 저절로 뜨는 게 부담스러우신 분은 스위치는 끄고, 필요할 때만 버튼을 누르시면 돼요. 카드 제목 옆에 마지막 결과가 작게 뜨고(어제 08:12 완료), 실패하면 빨갛게 실패로 바뀝니다. 인증서·비밀번호를 아직 안 넣었으면 버튼이 [설정에서 준비하기]로 바뀌어 그 탭을 열어 줍니다 — 눌렀는데 아무 일도 안 일어나는 일은 없어요.

인증서 비밀번호는 이 컴퓨터에만 저장됩니다

윈도우 계정에 묶인 암호로 잠가 두기 때문에, 파일을 복사해 가도 다른 컴퓨터·다른 계정에서는 풀 수 없습니다. 프로그램 안에서도 저장된 비밀번호를 다시 꺼내 볼 수 없게 막아 두었습니다(넣기와 지우기만 됩니다).

공용 컴퓨터에서는 켜지 마세요. 지울 때는 [업무포털] 탭의 [비밀번호 지우기]를 누르시면 됩니다.

컴퓨터를 켠 직후에는 조금 기다렸다 엽니다

부팅 직후에는 인터넷이 아직 안 붙었거나, 인증서 보안 프로그램(AnySign 등)이 아직 뜨는 중이라 실패할 수 있어요. 그래서 기본으로 20초 뒤에 열고, 보안 프로그램이 준비될 때까지 더 기다립니다. 컴퓨터가 느리면 45초 뒤로 바꿔 보세요.

자동으로 하지 않고 필요할 때만 쓰시려면 [직접 누를 때만]으로 두시면 됩니다.

이런 점을 알아 두세요

로그인하는 모습이 화면에 그대로 보입니다(몰래 하지 않습니다, 5~10초). 평소 쓰시던 브라우저 창은 건드리지 않고 새 창이 하나 열립니다 — 크롬을 켜 두셨어도 괜찮습니다.

교육청이 포털 화면을 바꾸면 실패할 수 있는데, 그때는 열린 창에서 평소처럼 직접 로그인하시면 됩니다. 인증서 자체와 보안 프로그램은 원래 쓰시던 그대로입니다.

업데이트

새 버전이 나오면 알려드려요.

v3.15부터는 앱이 받아서 설치까지 합니다. 앱을 켰을 때 새 버전이 나와 있으면 “새 버전이 나왔습니다. 지금 업데이트할까요?” 하고 여쭙습니다. [지금 업데이트]를 누르시면 받는 것을 막대로 보여 드리고, 다 받으면 그대로 설치한 뒤 새 버전으로 다시 열립니다. 설정과 자료는 그대로 유지됩니다.

  • 받는 도중 [취소]를 누르실 수 있습니다. 학교 인터넷이 막아 받지 못하면 받는 곳을 열어 드려요 — 예전처럼 직접 받아 설치하셔도 됩니다.
  • 묻는 것이 번거로우시면 설정 → [의견] 탭 → 새 버전에서 “알리지 않음”으로 바꾸실 수 있어요. 그 상태에서도 [지금 확인]은 언제든 됩니다.
  • 알림을 놓쳤다면 설정 → [의견] 탭의 “지금 확인” 뒤 [지금 받아서 설치하기], 트레이 메뉴 맨 위 “새 버전 받기”, 또는 이 페이지 맨 위 [지금 다운로드] 버튼을 쓰세요.
  • 직접 받으셨다면 새 설치 파일을 그냥 실행하면 기존 위에 덮어 설치돼요. 설정·기록은 유지됩니다.

그 이전 버전을 쓰고 계셨다면, 최신 버전을 한 번은 직접 받아 설치해 주세요. 그다음부터는 새 버전이 나올 때 자동으로 알림이 뜹니다.

  • 생기부 엑셀·한글·CSV 내보내기 파일에도 학반·이름이 들어갑니다. 학교 규정에 맞게 보관해 주세요.

지우는 방법

설정 → 데이터 탭 → [처음 상태로 되돌리기]를 누르면 저장된 내용이 모두 지워집니다. 컴퓨터를 반납하거나 업무를 인계할 때 한 번 눌러 주세요. 이미 내보낸 백업·엑셀 파일은 따로 지우셔야 합니다. 프로그램을 삭제해도 설정 폴더는 남으니, 지우려면 %APPDATA%\TeacherDesk2 폴더를 함께 삭제하세요.

자주 묻는 질문 · 문제 해결

막힐 때 여기부터 확인해 보세요.

  • 설치할 때 파란 경고창이 떠요 — 서명 안 된 무료 프로그램이라 정상입니다. [추가 정보] → [실행]으로 진행하세요.
  • 백신이 파일을 막아요 — 잠시 허용/신뢰로 풀고 설치한 뒤 다시 켜 두면 됩니다.
  • AI(생기부·도우미)가 안 돼요 — 설정 → AI 탭 → Gemini 키를 넣고 [키 확인] 하세요(04번 참고).
  • AI를 많이 쓰면 한도에 걸려요 — 무료 키는 분당 횟수 제한이 있어요. 몰아 쓰다 잠깐 막히면 1분쯤 쉬었다 다시 누르면 됩니다(한 번에 몰기보다 나눠 쓰면 매끄러워요).
  • 날씨가 안 떠요 — 설정 → 학교의 “이 지역으로”에 시·군·구만 넣어보세요(예: “구미”). 학교 인터넷이 막혀 있으면 안 나올 수 있어요.
  • 급식·학사일정이 비어 있어요 — 학교가 NEIS에 올린 만큼만 나와요. 비었으면 학사일정표 파일을 올려 채우거나 NEIS 키를 넣어 보세요.
  • 위젯이 바탕화면 아이콘을 가려요 — 설정 → 화면 탭에서 위젯 모드를 쓰면 빈 곳 아이콘이 그대로 클릭돼요. Ctrl+Alt+D로 앞뒤 전환도 됩니다.
  • 다른 컴퓨터로 옮기고 싶어요 — 설정 → 데이터 탭의 설정 내보내기로 저장한 파일을, 새 PC에서 설정 가져오기로 불러오면 돼요.
  • 화면 위쪽에 빈 여백이 넓어요 — 전광판을 켜 두면 그 띠가 지나갈 자리로 화면 맨 위 40px을 늘 비워 둡니다. 그런데 전광판에 띄울 내용(직접 쓴 글이나 구글 시트 주소)이 비어 있으면 띠가 안 뜨기 때문에, 자리만 남아 여백이 넓어 보여요. 독의 📢 전광판을 끄시면 여백이 40px → 12~34px(화면 여백 설정값)로 줄어듭니다. 전광판을 쓰실 거면 내용만 채워 넣으시면 됩니다.
  • 사양이 낮은 PC에서도 괜찮나요? — 씁니다. 다만 기본 설정 그대로면 무거울 수 있어요. 무거운 건 카드의 유리 흐림 효과인데, 카드 뒤 바탕화면을 흐리게 비추느라 그래픽카드가 화면을 그릴 때마다 다시 계산합니다. 위젯이 여러 장이면 그만큼 겹쳐요. 램·CPU는 멀쩡한데 화면만 뚝뚝 끊긴다면 대개 이것입니다. 아래 [사양이 낮은 PC 권장 설정]대로 두면 그 계산이 아예 멈춥니다.
  • 컴퓨터가 많이 느려지나요? — 넉넉한 PC에서는 크롬 탭 두세 개 켜 둔 정도입니다(가만히 둘 때 CPU 1% 미만, 램 300MB 안쪽). 램이 8GB 이상이면 신경 쓰지 않아도 됩니다. 4GB이거나 SSD가 아닌 PC라면 아래 권장 설정을 맞춰 주세요.
  • 맥에서도 되나요? — 지금은 Windows 전용이에요.
  • 여기에 없는 문제가 생겼어요 — 설정 → 의견 탭에서 바로 알려 주세요. 어떤 상황에서 그랬는지 한 줄이면 충분합니다. 익명으로 가고, 하나하나 다 읽습니다. 고친 내용은 같은 탭 공지에 올라와요. (v2.2.56부터)

① 카드 질감을 [지면]이나 [화이트보드]로 (설정 → 디자인) — 효과가 가장 큽니다. 기본(유리)만 흐림 효과를 쓰고, 나머지 다섯 질감(지면·메모지·화이트보드·칠판·터미널)은 흐림이 아예 꺼집니다.
「카드 진하기」를 100%로 올리는 것으로는 안 됩니다 — 카드가 불투명해 보여도 흐림 계산은 그대로 돌아요. 질감을 바꿔야 멈춥니다.

② 안 보는 위젯은 끄기 (설정 → 위젯) — 흐림은 카드 한 장마다 계산합니다. 위젯이 아홉 장이면 아홉 겹이에요. 잘 안 보는 것을 끄면 그만큼 줄어듭니다. ①과 함께 하면 가장 확실합니다.

이렇게 두면 뒤에서 하는 일은 1초마다 시계 숫자를 바꾸는 정도만 남습니다. 자동 시작을 켜 두셨다면, SSD가 아닌 PC에서는 켤 때 가장 느린 순간에 겹치니 꺼 두고 필요할 때 바로가기로 켜는 것도 방법입니다.
