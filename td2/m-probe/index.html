TD2 폰 연결 시험

PC 간 동기화 자료를 폰에서 읽을 수 있는지 재는 시험 페이지입니다. 학생 자료 내용은 화면에 띄우지도, 어디로 보내지도 않습니다.

앱 안 브라우저에서 열렸습니다

구글은 앱 안 브라우저 로그인을 막습니다. 이 상태 그대로 한 번 로그인을 눌러 막히는지 보고, 그다음 아래 단추로 열어 주세요.

폰 연결 시험을 도와주세요

TeacherDesk2를 폰에서도 쓸 수 있게 하려고, 구글 로그인이 잘 되는지 재는 중입니다. 5분이면 끝나요. 위에서부터 파란 테두리 칸의 버튼만 차례로 눌러 주세요.

구글 계정으로 로그인하지만, 이 시험이 쓸 수 있는 곳은 구글 드라이브의 «이 앱 전용 숨김 칸»뿐입니다. 메일·사진·문서는 볼 수 없고, 작은 시험 파일을 만들었다가 바로 지웁니다.

시작하기 전에

  • 사파리로 열어 주세요. 카카오톡에서 주소를 눌러 카톡 안 화면으로 열렸다면, 화면 아래쪽 «⋯»(또는 공유 버튼)을 눌러 «Safari로 열기»를 누릅니다.
  • 구글 계정(Gmail 주소)이 필요합니다. 없으시면 카카오톡으로 «구글 계정 없음»이라고만 알려 주셔도 됩니다.
  • 와이파이·데이터 어느 쪽이든 괜찮고, 5분 정도 걸립니다.

    이럴 땐 이렇게

    어느 칸을 해야 할지 모르겠어요
    파란 테두리가 있는 칸이 지금 할 차례입니다. 초록색 칸은 끝난 칸이라 설명이 접힙니다.
    버튼을 눌렀는데 아무 반응이 없어요
    3초쯤 기다렸다가 한 번 더 누릅니다. 그래도 그대로면 화면을 아래로 끌어내려 새로 고친 뒤 다시 누릅니다.
    빨간 글씨(✗ 안 됨)가 나왔어요
    실패도 꼭 알아야 하는 결과입니다. 고치려 하지 말고 다음 칸으로 넘어가 «결과 보내기»를 해 주세요.
    중간에 페이지를 닫았어요
    같은 주소(아이콘으로 했다면 아이콘)를 다시 열면 기록이 남아 있어 멈춘 칸부터 이어집니다.
    시험이 끝난 뒤 정리하고 싶어요
    홈 화면 아이콘은 길게 눌러 삭제합니다. 구글 연결은 구글 계정 관리 → 보안 → «타사 앱 및 서비스»에서 TeacherDesk2를 골라 연결을 삭제하면 됩니다. 드라이브에는 시험 파일이 남지 않습니다.

    순서

    1. 크롬에서 팝업으로 로그인 → 드라이브 시험
    2. 이동해서 로그인도 한 번 → 드라이브 시험
    3. 크롬 메뉴(⋮) → 홈 화면에 추가 → 생긴 아이콘으로 열어 1·2를 다시
    4. 한 시간 뒤, 하루 뒤에 아이콘으로 다시 열어 조용히 다시 받기
    5. 그때마다 결과 복사해서 보내 주기

    1. 로그인

    PC 동기화에 쓰는 구글 계정으로 로그인하세요. 권한은 «앱 전용 숨김 칸»만 요청합니다.

    2. 드라이브 시험

    쓰기 시험은 m-probe.json 작은 파일을 만들었다가 바로 지웁니다. PC 동기화 파일은 읽기만 합니다.

    3. 조용히 다시 받기

    로그인 화면 없이 새 열쇠를 받는지 봅니다. 열쇠가 살아 있어도 바로 눌러 시험할 수 있습니다. 로그인을 한 번 하면 계정이 저장돼 지정해서 보냅니다.
