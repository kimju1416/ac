TD2 폰 연결 시험

PC 간 동기화 자료를 폰에서 읽을 수 있는지 재는 시험 페이지입니다. 학생 자료 내용은 화면에 띄우지도, 어디로 보내지도 않습니다.

앱 안 브라우저에서 열렸습니다

구글은 앱 안 브라우저 로그인을 막습니다. 이 상태 그대로 한 번 로그인을 눌러 막히는지 보고, 그다음 아래 단추로 열어 주세요.

지금 이 폰

기기
여는 곳
저장 자료

순서

  1. 크롬에서 팝업으로 로그인 → 드라이브 시험
  2. 이동해서 로그인도 한 번 → 드라이브 시험
  3. 크롬 메뉴(⋮) → 홈 화면에 추가 → 생긴 아이콘으로 열어 1·2를 다시
  4. 한 시간 뒤, 하루 뒤에 아이콘으로 다시 열어 조용히 다시 받기
  5. 그때마다 결과 복사해서 보내 주기

1. 로그인

PC 동기화에 쓰는 구글 계정으로 로그인하세요. 권한은 «앱 전용 숨김 칸»만 요청합니다.

2. 드라이브 시험

쓰기 시험은 m-probe.json 작은 파일을 만들었다가 바로 지웁니다. PC 동기화 파일은 읽기만 합니다.

3. 조용히 다시 받기

로그인 화면 없이 새 열쇠를 받는지 봅니다. 열쇠는 한 시간이면 끝납니다.
