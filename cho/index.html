🌻 3~4학년군: 교과 개념어 등장, 비교·분류 활동 가능

🌺 5~6학년군: 추상적 개념, 논리적 설명, 비판적 사고 포함

📐 성취기준 코드 입력 시 교육과정에 더 정확히 연계됩니다 (세특에 특히 중요)

💬 결과: 봄꽃 사진 4장 중 맞는 이름 고르기 게임. 맞추면 꽃잎 폭죽 + "잘했어요!" 효과. 10문제 완료 시 "봄꽃 박사" 칭호 수료증 표시.

2번3~4학년군 / 수학 / 성취기준: 수와 연산 영역 — 분모가 같은 분수의 덧셈과 뺄셈 (코드는 NCIC에서 확인)
💬 결과: 학생별 특성을 반영한 세특 문구 생성. 성취기준 연계, 구체적 행동 서술어 사용, 200자 내외.
💡 꿀팁: 0번에 학생 특성을 구체적으로 넣을수록 좋아요. "발표를 잘 함" → "모둠 토의에서 먼저 의견을 제시하고 친구 의견을 경청하며 정리함"처럼요.
🟢
예시 7— 구글 슬라이드 10장 (5학년 과학 / 태양계)
0번5~6학년군 / 과학 / 태양계와 별
핵심어: 태양계, 행성 8개, 공전, 자전, 별자리
1번구글 슬라이드(Google Slides) 형식으로 내보낼 수 있는 수업 발표 자료 10장 — 제목·내용·이미지 설명·발표자 노트 포함
2번5~6학년군 / 과학
4번비주얼 씽킹 / 발문 전략
💬 결과: 도입1→핵심개념5→활동2→정리1→퀴즈1장, 슬라이드별 제목·본문·이미지 설명·발표자 노트 마크다운 생성. 구글 슬라이드에 복붙하면 됩니다.
💡 팁: 생성 후 "3번 슬라이드 내용을 더 쉽게 설명해줘" 등 후속 요청으로 수정 가능해요.

추가 요청생성 후 AI에게: "타이머 기능도 같은 앱에 추가해줘"
💬 결과: 학생 이름 입력 → 모둠 수 설정 → 셔플 애니메이션 배정 → 인쇄 기능.
